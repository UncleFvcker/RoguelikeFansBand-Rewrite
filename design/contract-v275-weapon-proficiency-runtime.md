# Contract v275：逐武器熟练度运行时

## 范围

本契约把包 1.275.0 已导入的职业逐武器表接入权威战斗状态，不新增 item、ability、affix
或其他内容 ID。当前正式消费者是 Warrior、固定死亡领域 High-Mage、Archer 和固定死亡
领域 Paladin。

## 权威状态与命中

- `CharacterProgress.weapon_proficiencies` 是按规范基础物品 ID 排序的稀疏表，只记录高于
  当前职业出生值的训练值；未记录项直接读取职业表的 `initial`。
- 神器和特殊变体通过 `weaponProficiencyBaseItemId` 与基础武器共享一项进度。
- `< 4000` 为生疏、`< 6000` 为入门、`< 7000` 为熟练、`< 8000` 为专家，8000 为大师。
- 近战、投石索和弓的熟练度命中值为 `(current - 4000) / 200`；轻弩和重弩为
  `current / 400`。命中检定应用该值乘以 `BTH_PLUS_ADJ = 3`，不改变射速或破损率计算。

## 成长与 RNG

- 普通近战在一次攻击命令中按装备武器训练一次，发生在命中检定前，不按多段攻击次数
  重复；即使命中失败仍可成长。职业能力触发的额外近战不走这个普通训练入口。
- 射击只在弹道首次碰到怪物时训练；射空不成长，也不为熟练度推进 RNG。
- 玩家最低可训练怪物等级、怪物允许的最高训练值，以及按当前熟练度衰减的成长量均使用
  RFB master `skills.c` 的插值表。成长整数部分不抽 RNG；仅概率余数非零时执行一次
  `bounded(10)`。
- 本次攻击使用训练前已经解析的命中值。只有熟练度整数命中加成跨档时才发送提升消息。

## 存档与版本

- `PlayerProgressSaveDto.weaponProficiencies` 为必填数组；新角色写入空数组。
- 载入拒绝缺失字段、重复 ID、未知/非武器 ID、非规范别名、值不高于出生值或超过职业
  上限的数据；不保留旧开发存档兼容路径。
- Protocol 为 1.178，State Hash Schema 为 v89，save 容器仍为 v1，active baseline 为
  contract-v275，内容包保持 1.275.0。

角色面板中的逐武器列表与等级文字不属于本契约，留给后续 UI 提交。
