# Contract v231：荒野卷动坐标模型

状态：第一步已实现。协议 `1.159`，内容包 `1.226.0`，State Hash Schema `v79`，
active baseline `contract-v231`；save 容器保持 v1，不兼容旧开发存档。

## 目标

为 RFB 式 3×3 荒野卷动建立稳定的权威坐标和几何边界，不在本阶段引入半成品
区块缓存、暴露条带怪物分配或移动事务。

## 权威模型

- 动态荒野层固定为 96×33，正好划分为 3×3 个 32×11 区块；城镇和地下城
  继续使用各自定义的尺寸。
- `wildernessPosition` 继续表示玩家所在的粗粒度世界格。
- 新增 `wildernessViewOffset: Position`，两个分量均为 `-1..=1`，表示玩家世界格
  相对当前 3×3 视口中心的区块偏移。新游戏从 `(0,0)` 开始。
- 非零偏移只允许出现在 local 尺度的动态荒野层；非法范围或错误场景在载入时
  作为无效存档拒绝。
- 视口偏移随存档往返并进入 state hash，避免未来卷动状态脱离确定性边界。

## 本阶段刻意不做

- 玩家进入外侧三分之一区域时尚不触发区块平移。
- 当前走出动态荒野边缘的兼容路径仍会重建完整相邻世界格。
- 尚未保留重叠地形、实体与地面物品，也未按新暴露条带比例补充怪物。

下一阶段应在普通移动结算中检测 32×11 区块边界，平移一个区块，原子迁移重叠
状态，并在偏移越过 `-1..=1` 时更新 `wildernessPosition`。

分代绝对区块采样和派生缓存已由 [contract-v232](contract-v232-wilderness-evolving-terrain-cache.md)
完成；动态状态平移仍待后续阶段。

## 验证

- 单元测试锁定 96×33、32×11 和 3×3 几何关系。
- 存档测试覆盖零偏移、非零合法偏移往返和越界拒绝。
- 动态荒野生成、坐标确定性、硬边缘兼容路径和城镇返回分别由聚焦测试覆盖。
- 协议 TypeScript 绑定与 JSON Schema 由生成器同步，不手工维护。
