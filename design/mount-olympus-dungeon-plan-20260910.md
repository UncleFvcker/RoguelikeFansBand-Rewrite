OL1 实施基线为已合并三个方向的 `main@befb411eb464b67d0a75f23d6561d3382c9395b3`，本方向分支为 `codex/dungeons-towns`，工作树 `D:/codex/RoguelikeFansBand-Rewrite-dungeons-towns`。当前版本见[状态页](../docs/status.md)，后续按实际模型变化确定，不预留编号。

权威来源是 `D:/codex/Frogcomposband/master` 的 `master` Git ref，规划及 OL1、OL2 实施实际提交均为 **`a0d92b6378d148c5262cc236b8fa6ed2ca06a54c`**；读取均来自 Git 对象。

## 3. 当前能力与真实缺口

### 神系激活和怪物资格

`src/variable.c` 的默认 `pantheon_count = 2`、`game_pantheon = 0`；`src/dungeon.c::_suppress_extra_pantheons` 从四个神系选出两个，抑制未选中的地牢及相应主神系成员。`monster2.c::get_mon_num` 还区分神系地牢、普通地牢和荒野中的生成资格；召唤有自己的神系及可用性检查，不能直接套用普通生成过滤器。

OL1 已接入四个主神系 tag 与四种 `*2` tag，补回正式怪物的 31 处次级标记并修正导入选择表；新游戏保存 `activePantheons` 位掩码，地牢可用 `pantheon: 1..4` 关联。普通／环境分配及随机召唤区分神系地牢、普通地牢与地表。`SUMMON_PANTHEON` 请求未激活神系时依原版改用唯一怪物类别，仍经过抑制及地点筛选；死亡唯一种复活只检查抑制，不套普通地点限制；固定家族召唤不检查抑制，继续遵守唯一种存活／死亡额度。家族召唤的存档来源验证复用原有候选表。

主标记与 `OLYMPIAN2` 等不能合并成一个类别：主标记用于神系成员身份，`*2` 参与 M 行偏好和源码的域外分配例外；只带 `*2` 的怪物不自动成为主神系成员。优先复用现有 actor tags、DungeonDefinition 和 Game 状态职责，仅在缺少真实表达时增加字段，不另建神系管理器或四套分配流程。

本批采用源码当前默认的“激活两个神系”，**不为了保证新入口总出现而固定选中奥林匹斯**，也不顺带做一套出生选项 UI。已开放种族若触发源码保留神系规则，必须一起接通；未开放的半神亚种／怪物种族身份分支记录边界，不以新增占位职业或空调用代替。

### 地形与生态

灾难区已有 `wallMix`，普通地牢已有自由房间、cave/cavern、河流、通道、无门和楼梯流程。奥林匹斯应沿用这些能力，把 **40% 永久填充墙**与 **GRANITE 房间边界**分开处理；不能把全图房间外墙改成永久墙，也不能让后涂地形封死路径。

采用本项目既有大地图尺寸／预算适配，实施时固定并记录实值；96×33 可作为首个验证配置。核实 CAVE／CAVERN 选择和水河触发的实际消费者，不直接复制竞技场的六个圆房间、每房单怪、等级下限、禁伴随或零地面战利品。普通地面物品、金币、陷阱、怪物伴随和死亡掉落保留正常地牢语义；未承接的 vault／房间类型如实记录，不能伪加源不存在的 NO_VAULT。

### 神祇掉落、奖励与食物

宙斯 actor 已包含 15000 HP、速度 137、抗性、呼吸、精神之矛、驱散、反魔及召唤等定义；有定义不等于所有战斗与掉落消费者已验收。当前正式 items 中未找到宙斯神器 256 和 Ambrosia；实施前与法术道具方向的已提交内容核对，优先复用其真实交付。

`src/xtra2.c` 还为其他奥林匹斯诸神指定各自的神器掉落。应列出**本批实际会进入生成／召唤池的神祇**及对应 special-drop 清单，逐项核对物品、几率、唯一性、诅咒和激活；不能只补宙斯而悄悄省略本批会遇到的其他神祇掉落，也不因此全量重导无关神器。

宙斯神器的源定义是 `a_info:256`，有 PERMA_CURSE、QUESTITEM、AURA_ELEC 及 BALL_ELEC 激活等实际行为。合法使用、不可移除／诅咒、唯一性和保存边界须由现有装备、神器与激活消费者承接。Ambrosia 的食用效果依据 `src/cmd6.c` 落实，生成限制进入现有物品分配边界；不是只在说明文字中写“奥林匹斯限定”。

还有一个守卫边界：现有家族召唤候选包含宙斯，而源 `_dungeon_boss_death` 按当前地牢及最终守卫种类判定，没有要求必须在 90 层。实施时须核对神祇召唤守卫的实际可用性；若能在奥林匹斯非末层提前击杀宙斯，应正确登记征服、发奖并阻止末层复活，不能只凭末层固定实例 ID 判定。地牢外击杀的行为也按源核实，不擅自授予奥林匹斯征服。
