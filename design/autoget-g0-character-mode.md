# G0：每角色自动拾取模式

状态：已实现。协议 `1.154`，state hash Schema `v75`，contract 基线 `v217`；save 容器保持 v1，旧开发存档不兼容。

## 原版依据

RFB `master` 的 `do_cmd_autoget()` 使用两个选项决定 Ctrl+G 行为：自动获取 `=g` 铭文物品，或获取墨家名器判定为需要的物品；两个选项默认都关闭。本项目将玩家当前选择规范化为单个三态值，使目标类别保持明确。

## 本阶段边界

- `AutoGetModeDto` 只有 `off`、`ammo`、`wanted` 三个合法值，新角色默认 `off`。
- 模式属于角色的墨家名器配置，由 `ConfigureMogaminator` 与当前语言规则文本原子更新。
- 无效规则文本会拒绝整次应用，既有模式和规则均保持不变。
- 模式通过 `MogaminatorDto` 投影到墨家名器编辑器，并由原生下拉框选择。
- 模式进入 save、回放和 state hash；它不随界面语言切换而改变。

G0 不增加 Ctrl+G 命令，不搜索目标、不移动玩家、不拾取物品。后续阶段直接读取该三态配置实现原版目标资格和连续旅行。
