# Contract v289：坐骑经验、进化与骑乘羁绊

状态：已实现。Protocol `1.191`，State Hash Schema `v95`，内容包 `1.302.0`，save v1。

## 内容与 ID

- 本批不新增 item、ability、material 或 affix ID。坐骑用药复用现有轻伤、重伤、致命伤、
  治疗、*治疗*、生命与速度药水。
- `ActorDefinition.evolution` 保存稳定目标 actor ID 与经验阈值。RFB master 共 348 条关系；
  当前本地两端都有定义的 320 条关系映射为 315 个独立 actor 定义，因为 5 组原版同名重复
  记录拥有完全相同的目标和阈值。另有 13 条关系缺少目标 actor，暂不生成残缺定义。
- Horse 按 `70` 经验进化为 Unruly horse。导入审计使用权威英文名映射稳定文件 ID，不把
  已漂移的数字序号写入运行时内容。

## 经验、进化与羁绊

- 宠物经验为 `目标经验值 × 目标等级 / (宠物等级 + 2)`，地表再除以 5。普通宠物击杀时
  玩家取得 1/5、宠物取得余下 4/5；满羁绊当前坐骑击杀时双方都取得完整值。满羁绊时玩家
  击杀还让当前坐骑取得该公式的 1/10。
- 玩家或当前坐骑击杀时，羁绊按目标等级增长，封顶 10000。2500 解锁治疗类药水，5000
  解锁速度药水，10000 解锁完整经验共享。更换坐骑、死亡、解散、失控或进化会重置；普通
  下马和同一实体楼层往返保留。
- 进化保留实体 ID、控制关系、骑乘状态与既有状态；经验归零，外观清除，速度与抗性切换为
  新形态，最大生命按新形态重新掷取，当前生命按旧生命比例换算。进化后的同一坐骑从 0
  羁绊重新培养。

## 药水、UI 与持久化

- 治疗骰与固定值严格使用 RFB；生命药水恢复到满生命。速度药水未加速时为 `1d25+15`，
  已加速时只延长 5，后者不消耗效果 RNG。
- 物品栏用既有 `UseItem` entity target 给当前坐骑使用药水；宠物面板显示种类、等级、
  经验/阈值、骑乘状态和羁绊百分比。
- actor 经验与羁绊进入 save/state hash，旧开发存档不兼容。全部 26 条 active fixture 因
  公共权威投影刷新至 `contract-v289`，零 waiver。
