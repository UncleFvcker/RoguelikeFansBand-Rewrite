# O1：物品发现权威状态

状态：已实现。协议 `1.148`，state hash Schema `v71`，contract 基线 `v205`；save 容器保持 v1，旧开发存档不兼容。

## 边界

- `ItemPropertyKnowledgeSaveDto.discovered` 按稳定物品实例 ID 保存玩家是否已经发现该物品。
- 玩家当前视野内的地面物品，以及物品探测命中的地面物品，会被标记为已发现。
- `GameSnapshot.items` 和本地地图 `CellDto.itemId` 不投影未发现的非金币地面物品，避免通过协议读取隐藏实例。
- 发现状态随拾取、丢弃、偷窃、怪物携带和楼层存储保持；物品实例消失后不再序列化其知识。
- `discovered` 不参与物品堆叠兼容；鉴定、词缀知识与发现状态仍各自保持权威。

本阶段不实现 Shift+O 物品/地形列表界面；该界面后续直接消费本阶段收紧后的安全投影。
