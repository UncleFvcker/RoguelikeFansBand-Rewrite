# Contract v233：荒野区块卷动与动态状态迁移

状态：第三步已实现。协议 `1.160`，内容包 `1.226.0`，State Hash Schema `v79`，
active baseline `contract-v233`；save 容器保持 v1。

## 卷动事务

- 玩家进入 `x < 32`、`x >= 64`、`y < 11` 或 `y >= 22` 的最外侧区时，视口沿
  对应轴平移一个 32×11 区块；对角移动可在同一事务中同时平移两个轴。
- `wildernessViewOffset` 在 `-1..=1` 内推进；越界时同步调整
  `wildernessPosition` 并从另一侧偏移继续，使绝对中心区块每次只移动一格。
- 卷动发生在玩家真正落位前。目标格通行与占用先按旧视口判断，随后统一换算
  坐标，因此陷阱、拾取、环境伤害和事件使用卷动后的局部位置。
- 跨入正式城镇世界格时继续切换既有独立城镇层；本阶段不把城镇建筑嵌进荒野
  视口。

## 动态状态

- 新视口先从当前代区块缓存拼接基础地形，再把重叠范围内的运行时地形、光照、
  已探索和已揭示状态平移覆盖；新暴露条带保持未探索。
- 玩家、怪物、坐骑、地面物品、金币与召唤警戒点使用同一 translation。离开
  视口的普通实体、地面物品及金币被裁剪；怪物携带物随怪物删除。
- 任一 pack 成员离屏时整组裁剪，防止留下无首领或孤立成员。被裁剪实体同时从
  `removedEntities` 和运行时分裂余数中移除。
- 本阶段本身不在新条带生成怪物；后续 contract-v234 已按新暴露面积补充怪物，
  并保留初次进入的道路 4 次、非道路 10 次分配基准。

## 协议与持久化

`GameUpdate.mapTranslation` 可选投影本次局部地图平移，前端据此移动正在执行的
本地自动旅行目标。地图与视觉格继续通过既有全量 changed 集合刷新，不引入新的
渲染分块协议。

卷动没有新增存档状态：已有 position、offset、seed 以及活动层动态状态足以精确
恢复。派生地形缓存和单次 `mapTranslation` 不保存、不进入 State Hash。
