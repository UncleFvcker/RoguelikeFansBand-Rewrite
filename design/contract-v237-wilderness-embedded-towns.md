# Contract v237：连续荒野中的可变尺寸城镇

状态：已实现。协议 `1.160`，内容包 `1.227.0`，State Hash Schema `v79`，
active baseline `contract-v237`；save 容器保持 v1。

## 连续地表

- `WildernessLocationDefinition::Town.mapOrigin` 指定城镇原尺寸地图左上角在所属
  96×33 世界格内的位置。Outpost 保持 96×32，Anambar 保持 23×11。
- 荒野缓存只生成 seed 驱动的基础地形；可见城镇切片随后覆盖到视口，因此城镇
  地形不随 `wildernessSeed` 改变，城镇外微观地形仍会演化。
- 玩家跨入或离开实际城镇矩形时保持同一动态荒野层，并继续投影既有
  `mapTranslation`。`currentTown`、商店、Home 和任务设施均由实际矩形及坐标换算
  派生，不保存额外 `insideTown` 状态。

## 城镇状态与切换

城镇继续复用原尺寸 `FloorState`。可见切片进入活动视口时加载地形、光照、探索、
揭示状态、实体、地面物品、金币、连接和区域；离开视口或进入世界地图、地下城前
写回同一 backing floor。玩家、坐骑和跟随召唤物仍属于活动层，实体 ID 不会同时
存在于活动层与 backing floor。

世界地图入口校验失败不改变 seed 或城镇状态；成功入口先写回城镇，再推进一次
`wildernessSeed`。从世界地图返回会重新合成荒野与城镇。从城镇进入地下城时暂时
激活原尺寸城镇 floor 复用既有楼层事务，返回后恢复原世界位置、视口偏移和城镇
局部落点。非零视口偏移允许随世界地图或地下城存档，供返回连续地表时恢复。

## 怪物边界

普通荒野初始生成与卷动条带生成只排除视口内实际城镇矩形，小城周围仍按荒野规则
生成；轮数按扣除城镇后的可用面积确定性折算。伏击仍只由世界地图触发，并继续
使用独立的 20 轮规则。当前没有独立的自然补怪调度器。

## 验收

- Outpost 与 Anambar 均按原尺寸嵌入，城镇从东、西、南、北方向卷入时重叠地形
  连续；seed 推进只改变城镇外地形。
- 城镇实体、物品、金币、探索和揭示状态离屏、世界图、地下城及存档往返后恢复。
- 商店、Home 和任务设施坐标随视口平移；走出小城矩形即恢复荒野状态。
- 城镇矩形内不生成随机荒野怪物，矩形外与新暴露条带仍可生成。
- `refresh-all` 与 `verify-all` 覆盖全部 471 个 exact fixtures，零豁免。

本契约不新增第二套相机、城镇专用渲染器、独立城镇缓存、协议字段或持久
`insideTown` 字段。
