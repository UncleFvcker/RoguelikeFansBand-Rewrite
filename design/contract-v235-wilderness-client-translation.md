active baseline `contract-v235`；save 容器保持 v1。

## 坐标同步

- 继续使用协议 1.160 已有的可选 `GameUpdate.mapTranslation`；视口向东卷动时，
  旧局部坐标统一增加 `{ x: -32, y: 0 }`，其他方向及对角卷动同理。
- 本地自动旅行目的地、查看光标和瞄准光标都使用同一 translation。targeting 的
  origin 与 cursor 同步平移，保证射程关系不变。
- 平移后仍在 96×33 视口内的光标继续保留；光标或 origin 离开视口时退出当前
  targeting，防止提交无效局部坐标。
- 查看和本地旅行选择的相机焦点同步到平移后的 cursor。

## 对象列表

- 打开的对象列表在每次权威更新后从最新 cells、设施、物品和玩家位置重建，
  因此显示坐标、距离和方向与卷动后的视口一致。
- 重建前记录选中对象的稳定 ID；对象仍存在时在新排序中恢复选择，离开视口时
  回到第一项。

## 保持简单

地图继续通过既有 `changedCells` 与 `changedVisualCells` 全量刷新。本阶段不增加
前端分块渲染器、缓存管理器、卷动动画或新的持久状态；协议保持 1.160，save
容器保持 v1，State Hash Schema 保持 v79。
