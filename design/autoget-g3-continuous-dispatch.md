# G3：Ctrl+G 连续调度

状态：已实现。协议保持 `1.156`，state hash Schema 保持 `v76`，contract 基线保持 `v219`。

- Ctrl+G 与小写 `g` 分离；世界地图不会启动自动拾取。
- 开始时先派发一次零耗时普通 `PickUp`，处理脚下物品。
- 前端锁定 Core 投影的对象 ID，连续派发单步 `AutoGet`；对象消失后才读取下一个目标。
- 前端不计算路径、距离或墨家名器结果，只读取每次权威更新。
- 玩家受伤、死亡、失明或混乱，出现可见敌人、满包、待确认、路线阻断、楼层切换、目标失效或无后续目标时立即停止。

连续调度不写入存档或 state hash，也不增加后台计时器；每一步都等待上一条命令完成。
