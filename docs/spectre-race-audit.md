## 2. 本体、当前形态与历史出生种族

原版 `src/races.c:8` 的 `prace_is_` 查询当前形态；`get_race`（约 529）优先临时变形，`get_true_race`（约 523）读取 `prace/psubrace`。**`prace` 是可永久变化的本体种族，并非永远不变的 `start_race`。** 首版计划中的“出生种族保底”表述据此修正。

重写 [progression.rs](../crates/rfb-core/src/game/progression.rs)的 `character_definitions` 用 `build.race` 作本体，临时状态 `granted_race_id` 覆盖当前 Race。被动、能力、同族、饮食和不死判断应沿用这个入口；本体特例单独明确，不能用当前 Race 代替。

| 场景 | 原版应有结果 |
| --- | --- |
| 人类暂时变为幽灵 | 获得当前形态的被动、穿墙、吸能和恐吓；墙内伤害没有本体幽灵的限额 |
| 本体幽灵暂时变为人类 | 不保留幽灵种族被动；若仍由其他来源获得普通穿墙，密度分支仍检查本体幽灵并限额 |
| 本体幽灵失去全部穿墙后留在墙内 | 走挤压分支，没有幽灵密度限额 |
| 本体永久变更 | 本体特例随新 `prace` 变化；不能绑定历史创建选择 |
| 死亡领域幽灵形态状态 | `IS_WRAITH` 状态有自己的墙内豁免；不等于变更为幽灵 Race |
| 临时变为幽灵 | 不重跑夜间出生、起始法杖/照明和出生美德 |

## 3. 地形、骑乘与行动能量

来源：`src/cmd1.c:4337` 的 `player_can_enter`、约 5177 的树木代价、5345 的穿墙能量；`src/monster1.c:712` 的 `monster_can_cross_terrain`；`src/xtra1.c:4903` 的骑乘被动调整；`lib/edit/f_info.txt` 的地形旗标。

- 普通通行、可飞越、可游泳和允许穿墙是不同资格。普通花岗岩有 `CAN_PASS`；永久墙没有。边界、占位、结界和特殊地形检查不能被穿墙跳过。
- 永久属性本身不是“一律不可进入”：原版山地虽永久，却可飞越。幽灵的浮空可以使它通过可飞越地形，这不是穿过永久墙。
- 骑乘时由坐骑通行规则接管；穿墙坐骑载人穿墙仍要求骑手也能穿墙。不能仅凭坐骑能力带普通人穿墙，也不能仅凭幽灵骑手带不会穿墙的坐骑穿墙。原版还会在骑乘非穿墙坐骑时清掉玩家 `pass_wall`。
- 成功进入 `FF_CAN_PASS` 地形且没有破墙等例外时，行动能量乘 `3/2`，正常 100 → 150。该计算不需要 RNG，亦不是每走一步立即扣一次墙内 HP。
- 原版树木有 `MOVE | CAN_FLY | TREE`，没有 `CAN_PASS`；幽灵穿行树木免树木额外代价，但不因此收取 150 能量。重写树木为不可步行且 `allowsWallPassage: true` 的适配表达，不能把该字段直接当作所有原版 `CAN_PASS` 语义，造成树木误伤或误加价。
- 传送另有 `FF_TELEPORTABLE` 前提（`src/spells3.c:273`），花岗岩不能因可穿墙就自动成为传送目的地。现有传送候选用可步行格，不应盲目替换成通行判断并放开所有墙。

## 4. 墙内密度、0 HP、恢复与状态结束

来源：`src/dungeon.c:1512–1654`，`process_world` 的十回合周期（约 3094、3431）；`src/defines.h:330` 的 `TURNS_PER_TICK=10`；`src/effects.c:6377` 的 `take_hit`。

原版每次世界 HP/SP 处理按以下顺序结算：

1. 当前格既没有 `FF_MOVE` 也没有 `FF_CAN_FLY` 才进入墙内分支。这里检查地形的可飞越旗标，不要求玩家此刻真的有飞行能力。
2. `IS_INVULN` 或 `IS_WRAITH` 直接免除这段伤害。
3. 基础伤害 `1 + level / 5`，整数除法。若有 `pass_wall`，`no_passwall_dam` 可免伤；否则为“密度”。本体 `prace == RACE_SPECTRE` 时先令 `dam = min(dam, chp)`。
4. 没有 `pass_wall` 时为“坚硬的岩石”挤压伤害；没有幽灵限额，也不能仅凭 `no_passwall_dam` 免掉此分支。
5. `dam != 0` 才设置 `cave_no_regen` 并调用 `take_hit(DAMAGE_NOESCAPE, ...)`。之后先恢复法力，再通过 `cave_no_regen` 抑制 HP 自然恢复。

必须保留的边界：

- 普通情况下本体幽灵可被扣到 **0 HP**，不是 1 HP；死亡判断是 `< 0`，重写已有对应 [BelowZero 伤害策略](../crates/rfb-core/src/game/damage.rs)和 `player_is_dead`。
- 限额发生在通用 `take_hit` **之前**。该函数还处理舍身等增伤、先见、无双和超越状态的 SP 抵扣；`DAMAGE_NOESCAPE` 不是跳过全部通用机制。不要将源代码的普通情形概括成绝对不死，也不要在最终伤害后再加一层无条件 HP 下限。尚未实现的职业姿态不为本批虚建。
- 在 0 HP 且仍有普通穿墙的本体幽灵，限额令本次 `dam=0`，这段代码不会设置 `cave_no_regen`；其他条件允许时仍可发生自然 HP 恢复。不能简单用“站在墙里”永久关闭恢复。
- 抑制标记取决于传给 `take_hit` 的非零伤害，即使后续被通用效果抵扣也已设置。法力恢复不因这个标记停止；主动治疗也不是自然恢复，不能统一封锁。
- 原版先墙内 HP/SP 处理，再扣状态时限。重写 [turn.rs](../crates/rfb-core/src/game/turn.rs)目前先状态 tick，再饥饿和自然 HP，后续装备恢复；没有墙内伤害。自然 HP 间隔已有 10 tick。必须验证剩余 1 tick 的豁免/形态与周期重合，不以“都是 10”代替时序验证。
- 等待/休息另有资源恢复入口；休息遇伤害会提前退出，须核对最后一次伤害回合的法力恢复不会被顺带跳过。装备恢复与自然恢复关系也应显式覆盖，不能让额外的 HP 恢复入口绕过抑制。

已有形态来源必须分别处理：

| 来源 | 原版规则 | 重写差异 |
| --- | --- | --- |
| 幽灵 Race | 普通穿墙，受上述密度伤害 | 待实现 |
| `IS_WRAITH` | 穿墙及墙内免伤，另有自身防护 | 死亡领域状态已有穿墙与伤害比例；墙内新规则须正确免除，不能误用 Race 保护 |
| `IS_PASSWALL`（穿壁/野性天赋来源） | `pass_wall` 和 `no_passwall_dam`，见 `src/xtra1.c:4481` | 按实际已有能力入口确认；不要把所有普通穿墙状态都赋予免伤 |
| 恶魔领主 | `src/races_mf.c:208` 设 `kill_wall`，通过破坏墙体前进 | 当前变形程序授予穿墙，属于既有适配错误；第二步处理关联回归时必须区分破墙，不能当作原版免密度穿墙的证据 |

原版 `set_wraith_form` 结束时（`src/effects.c:3009` 起）重算状态和显示，不强制移出墙体。重写状态结束同样不迁移位置。墙内失去通行后可以离开进入合法格，继续停留则受挤压；禁止凭空新增弹出、传送或存档自动挪位。

保存边界：[validation.rs](../crates/rfb-core/src/game/validation.rs)当前楼层只验证玩家坐标在范围内，缓存楼层却要求记录的玩家位置可步行（约 981）。合法穿墙停留、召回离层后的缓存位置，以及形态结束后困墙的合法历史都要保存/加载连续验证。不能只放宽所有坐标或要求加载时仍有穿墙能力，也不能破坏越界、地形元数据和其他实体校验。

## 5. 出生、饮食及现有共用消费者
