## 战法师本轮范围

新增一个 `demo.class.warrior-mage`，主领域固定奥秘。按已接入的九领域，副领域开放生命、咒术、自然、死亡、工艺、恶魔、圣战、毁灭，共 **8个Build**，沿用 `demo.build.warrior-mage-arcane-<second>` 命名约定。本批完成且无其他入口变化时，总入口为13个职业、102个Build。

依据为 `src/tables.c` 的 `realm_choices1/2`、`src/cmd5.c` 的选书/改换流程和 `src/warrior_mage.c`。奥秘不能重复作为副领域；已实现工艺应纳入，不能直接复制旧Mage菜单而漏掉它。源允许但未接入的领域单列缺口。本轮九领域对应288项职业施法参数，保留书内顺序与超过50级的不可达项。

完整交付包括正常出生、1—50级成长、双方自主学习/重复研习/施法、遗忘恢复、合法改换、两项职业能力、当前可达生成/奖励/设施、UI和桌面实战保存。高等级可使用明确记录的测试准备；不要求自然练至50级或完整通关。

## 已核对的区别与依赖

| 行为 | 来源及实施要求 |
| --- | --- |
| 出生与成长 | `warrior_mage.c`：短剑、软皮甲、双领域书；INT施法，生命105%、基础HP8、经验140%、宠物35。`m_info.txt N:6`为1级施法；导入对应技能/武器熟练度表，核对感知、美德及种族交叉 |
| 负重与近战 | 源负重430、武器33%、阈值1200，允许降低法力消耗且受手套负重影响；`combat.c`近战次数参数525/70/30。已有近战计算承接职业差异，不复制一套战斗规则 |
| 学习与容量 | `m_info.txt`的SORCERY书类决定自主选择法术，支持重复研习；主副熟练度1600/1400。`xtra1.c::calc_spells`普通双领域基础上限80、非LIFE书类加4，准确公式为 `min(adj_mag_study[INT] × L / 2,84)`，再加真实额外容量；不能给每级计算结果直接+4或复制Mage的96/Priest与Ranger的随机学习 |
| 失败与改换 | `spells3.c`额外副领域5%失败率名单不含战法师。复用真实背包/脚下书本改换、主领域保留、已付支出/旧领域历史和待确认保存；检查所有“仅Mage”判断是否应包含当前实际消费者，不一律放宽 |
| 生命转法力 | `warrior_mage.c`与`spells_h.c::hp_to_sp_spell`：25级、INT、标称费用0、基础失败50；实际按等级付生命，以实际生命伤害的1/5增加MP并截断至上限。核对`DAMAGE_USELIFE`、低血量/死亡、失败及回合语义，不能因费用字段是0而显示成免费 |
| 法力转生命 | `spells_s.c::sp_to_hp_spell`：25级、INT、标称费用0、基础失败50；MP满足`level/5`才扣除并治疗`level`点。MP不足时源CAST仍返回成功，实际提示、耗时与失败路径必须审计，不擅自改成无耗时拒绝 |
| 现有转换实现 | `mutations.rs`两个周期转换按1:1、随机触发，和主动能力不同。复用底层资源/伤害/治疗原语，保留突变原语义；只在实际逻辑相同处提取共享代码 |
| 神器卷轴与任务 | `artifact.c`为Mage bias / warrior bias 20。旧城堡1:4选择神器22“罗恩格林的”/219“魅力吊坠”；两神器与前者kind287“秘银链甲”均缺失，护身符底材已存在。激活原语可复用，但源22为治疗777/冷却300，219为恢复法力/冷却777，需按源后果组装。普通盗贼任务还需补长剑覆盖，不能沿当前阔剑默认值 |

沿[验证指南](testing.md)按实际影响运行检查；普通步骤以受影响路径为界，统一桌面与完整里程碑验收放第七步。牧师批次曾单独约定延后第二至第六步检查，该约定不自动沿用到新批次。内容变化更新pack/lock；类型变化才生成Schema/协议绑定。只有实际状态哈希/初始化/RNG等影响才按范围刷新契约，先解释差异，不为纯内容升级机械刷新。

种族职业方向在当前main实施，保留其他方向修改。两件必要神器或共享效果如出现真实并发重叠，按[并行协作](parallel-development.md)协调责任；这不是先行审批点，也不提前建立新通用框架。桌面使用既有Tauri/WebDriver和进程定向控件接口，不使用Computer Use或接管全局输入。自然高等级、完整通关与Android不在默认交付范围内。
