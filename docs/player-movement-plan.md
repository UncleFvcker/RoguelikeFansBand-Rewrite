# 角色移动与镜头平滑

## 当前实现

- Rust 按格结算；前端只维护显示位置，不改规则、回合、存档或 RNG。
- 玩家从分块角色绘制移出，使用独立字符／背景容器。它位于视野遮罩之上，避免旧格变为记忆格时把移动中的玩家遮掉；怪物、物品和地形仍受原遮罩约束。
- 同一局部地图、同一角色的一格手动移动约 100ms，立即起步并轻微减速落格。长按重复、奔跑、自动探索、局部寻路、未知物品寻路、auto-get 以及计数／宏中的相邻移动约 80ms 匀速。
- 原地攻击、开门、拾取和撞墙没有移动动画。传送事件、玩家被怪物移位、地图平移、换层、世界地图、读档和死亡直接落位；相邻传送也检查事件。
- 复用 Pixi ticker，以同一个分数坐标移动玩家并计算镜头，不额外叠加镜头拖尾。局部镜头保留地图边界，全图模式保留跟随边距；查看／瞄准焦点优先。
- 鼠标命中使用当前画面偏移。SVG 地图标记只更新父组位移／缩放，玩家高亮与瞄准框同步，不每帧重建路径或操作面板。
- 自动行动等待当前显示步完成再发下一步，最多一格正在显示，不建立待播队列。长按仍由系统重复键驱动，核心忙或动画未结束时丢弃重复事件；松键后不补发。快速独立点按可以提前结束旧过渡，保持真实路径拐点。
- Esc、点击、失焦和会话重置可立即解除自动行动等待；动画完成不会恢复已取消的循环。奔跑／探索无位移取消回包保留已结算一格的收尾。页面隐藏、减少动态效果、换层和销毁完成／清理过渡。
- 动画从接收更新后计时，不把核心处理时间计入第一帧。
- 逐格光照与视野遮罩使用角色同一帧的移动进度渐变；先保留移动前的格子外观，再随 100ms／80ms 的步进更新。只重绘当前分块内发生变化的遮罩，不重新计算 FOV，也不逐帧重建地形纹理。新进入视野的怪物随遮罩显现，失去可见性的怪物仍由最新核心投影立即移除。
- 光照／视野过渡与角色一起收尾；取消奔跑／探索保留当前步，换层、传送、快照、后台和减少动态效果同步落位。此项为撤回 shader 后新增的改动，专项用例已纳入后续 303 项前端定向验证并通过，已重新编译；普通 EXE 的新角色移动烟测通过。

## 近战碰撞动画

第一批源码已接入：依据玩家近战和变异近战的命中、落空、击杀事件及 `attackTarget`，让人物朝实际相邻目标短促前冲 0.2 格。约 45ms 出手、25ms 停顿、80ms 回位，八方向按相同距离归一化；一份更新中的多次攻击只播放一段。不移动站位、镜头、视野中心或光源，不更改核心结算与目标状态。

目标位置优先取攻击前投影，覆盖已死亡或被击退的目标。不可见目标没有实体投影时，仅在近战事件确认后使用移动／特殊行走／alter 的已知方向绘制人物出手；不生成隐藏怪物外观。换层、地图平移、传送、玩家移位或死亡不播放原地攻击；快照、后台、减少动态效果、换图和销毁复用原有动画收尾。长按／连续行动复用同一个显示忙碌状态和完成等待；快速独立操作结束旧动画后接续，不排队。

第二批源码已接入：接触时刻（约 45ms）短暂提亮目标字符；击杀时用攻击前的可见外观保留至接触，再于同一段动画内淡出。效果层位于视野遮罩之下，仅绘制目视且非模糊感知的目标；失去可见性时不绘制反馈。实际死亡、掉落、血量和目标选择仍即时消费核心状态，残影不参与交互。同目标多段攻击合并为一次命中／击杀反馈，落空不闪光也不震动。

命中镜头冲击沿攻击方向短促偏移，幅度不超过 2 个屏幕像素，并于 150ms 动画结束时归零。最终镜头偏移同时用于 Pixi 地图、光照、视野、SVG 标记和鼠标命中，HUD 不移动；人物出手偏移仍与跟随中心分开。设置 → 显示新增“近战命中时轻微震动镜头”，保存后生效并保留显式关闭值，不进入核心行为设置。关闭该项只停镜头冲击；系统减少动态效果时跳过整段攻击动画。后台、快照、换层、换图及销毁清理残影与镜头偏移。

新增 `player-motion.test.ts` 中的近战事件识别、不可见目标、八方向曲线、反馈时序与边界用例；补充显示设置的前端保存入口及原生序列化用例，输入等待复用已有覆盖。2026-09-16 已通过包含这些用例的 303 项前端定向验证及原生偏好专项，standalone 已包含这两批近战动画；近战演出尚未逐项实机视觉验收。

## 光照撤回

按用户要求撤回地图光照 shader：删除光照纹理、火把闪动、顶部受光、暖光随移动过渡及专用投影字段，恢复原逐格光照。协议源、TS／Schema 一起恢复为 1.300 对应版本。角色与镜头移动、标题页 shader、unique 彩虹均保留。

撤回后已按用户授权重新编译：`npm run build:standalone:debug` 更新 `target/debug/rfb-tauri.exe`，其中地图已恢复原逐格光照，无 NSIS。

撤回后验证：`player-motion`、`camera`、`map-display`、`render-world`、`render-profile`、`input-controller`、`status-panel`、`localization` 共 211 项前端用例及类型检查通过；`game::tests::lighting::` 24 项核心回归通过。核心光照／快照、协议源及生成物与 HEAD 原版本一致。未跑全量测试。

`node web/e2e/map-motion-spells-standalone.e2e.mjs` 使用新 EXE 在隔离目录正常创角，确认 `rust-content-lights-v1`、真实移动中间帧、700／1280／1920 宽度对应 2／3／4 列卡片、伤害显示、大写展开和无溢出，且无运行时异常。当前 `test-results/map-motion-spells/report.json` 与截图已更新为撤回后的证据。
