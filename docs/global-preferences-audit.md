## 合并后的控件与统一行为

按用户要求，以下九组作为 O2–O7 的实现范围。主表保留原版逐项追溯，运行配置只保存新版单一表达，不同时保存派生的旧布尔值。统一显示／固定行为不额外创建开关；此前撤回的资源条、英尺、跑步镜头覆盖和宠物移动打扰继续保持撤回。

| 合并范围 | 新版表达与默认 | 接入阶段与边界 |
| --- | --- | --- |
| `rogue_like_commands` 与其他操作预设 | 一个“键位方案”，沿用五套已有预设；默认 numpad | O2，复用现有输入预设；自定义映射仍是同一方案下的编辑入口 |
| `use_old_target`、`auto_target` | 一个“默认瞄准方式”：手动／旧目标／最近敌人／旧目标优先、否则最近敌人；默认最后一项 | O4，四种组合均保留。对怪物的地格／方向攻击按实例记忆；旧目标不可用且策略不允许最近敌人时回到手动选择；最近敌人无合法候选也回到手动。自动选择不自动提交攻击，宠物候选控制独立 |
| `auto_get_ammo`、`auto_get_objects` | 一个“自动取物范围”：关闭／弹药／规则选中的物品；默认关闭，复用 Off／Ammo／Wanted | O4，默认拾取、Mogaminator 启用与销毁策略各有独立语义，不能合并成这个范围枚举 |
| 四个 `view_*_lite` 光照着色项 | 由主题统一区分照明、当前可见与记忆区域；沿用当前主题，不保留四个开关 | O5/O6，高级配色覆盖外观；不改变地格记忆规则或陷阱侦测覆盖显示 |
| `graph_visuals`、`graph_floor/wall/tree_ascii` | 一个“图块方案”，沿用 ASCII／image；默认 ASCII，覆盖默认空 | O2/O6，细节进入同一字形编辑器，不新增地板／墙／树的独立开关，也不修改图片像素 |
| `plain_descriptions`、`abbrev_extra/all` | 列表用简洁名称，详情保留完整已知属性；没有全局描述详略开关 | O5，不实现旧缩写编码；未知物品仍用可知外观名称。紧凑列表待真实需求出现再增加 |
| `disturb_move/high/near` 等敌情打扰项 | 一套明确的敌情停止策略：沿用现有可见敌人即停；不增加重复开关或新的松紧档位 | O4，复用 Core 既有敌情检查，统一入口说明；受伤、异常、阻挡及各行动原有停止条件独立保留，普通宠物移动不纳入敌情 |
| `find_ignore_stairs/doors/veins` | 一个“跑步停靠点”多选：楼梯／敞门／已知埋藏财宝；默认仅楼梯选中 | O4，三个条件保持独立，选中表示遇到后停止，与源 ignore 值取反。`find_cut` 是路线几何选择，不是停靠点，仍保留独立切角选项且默认关闭；危险、路口等既有停止规则不变 |
| 危险怪物／危险招式边框及边框模式 | 将来合为一个“危险提示”；本批仍暂缓，不创建配置字段或占位控件 | 先具备可靠、仅基于已知资料的危险度投影。不得以等级估算替代完整预测，不开放忽略见闻的变体 |

合并验收：四种瞄准方式各有相应场景；自动取物枚举及跑步停靠点分别保持各条件含义；图块／主题／字形编辑只有一处权威配置。列表简洁显示仍保留操作标签与必要的已知区别，详情不丢失属性。PRF 别名只作为交换转换，不形成第二套运行设置。

## 统一菜单与快捷入口

按用户确认的方案，设置页面采用同一个入口和页面体系。快捷键直接定位对应页面或执行对应命令，不另建独立编辑器、草案副本或配置来源。

| 入口 | 页面／行为 | 实现阶段 |
| --- | --- | --- |
| 标题页“设置”、游戏内 `=` | 打开同一全局设置入口，导航到一般设置、字形、配色、高级导入与备份；自动拾取规则链接到 Mogaminator | O2 |
| `%` | 直接打开统一设置中的字形页面，与从 `=` 进入时使用同一编辑状态 | O6 |
| `&` | 直接打开统一设置中的配色页面，与从 `=` 进入时使用同一编辑状态 | O6 |
| `!` | 打开高级导入区并定位单行偏好指令输入；沿用 O7 的解析、预览、校验和应用路径 | O7 |
| PRF 导入／导出 | 放在同一高级导入区；只交换明确支持的子集，并列出无法表达的项 | O7 |
| JSON 备份／恢复 | 放在同一高级导入与备份区，完整导出已保存的全局偏好，包括键位、视觉覆盖及 Mogaminator 规则；恢复前预览并校验 | O2 |
| `$` | 保留自动拾取规则的直接重载命令；Mogaminator 内提供同一命令按钮，不要求先打开设置页 | O7 |

JSON 的完整备份范围是全局偏好，不包含角色存档、馆藏、成绩、笔记或会话寄存器。所有修改最终提交同一 `preferences.json`；PRF 文件是交换输入，`!` 不形成独立运行配置，`$` 只读取其中已保存的 Mogaminator 部分。规则重载不覆盖未保存草案，也不自动执行拾取／销毁。

上述按键使用现有命令分发和映射流程；输入框、规则文本框内正常输入这些字符，不触发全局导航。打开／切换页面复用当前设置会话，不重复弹出多个编辑窗口；沿用现有取消与未保存草案处理。标题页与游戏内入口编辑同一份配置，游戏内打开设置遵守已有连续行动停止边界。

验收关注入口等价性：从 `=` 与快捷键进入同一页面，修改后的显示与保存结果相同；PRF／单行导入共用校验，JSON 可完整往返；`$` 与编辑器重载按钮行为一致。页面导航不消耗回合，不执行物品操作；O8 收口后已执行对应验证。

R/K 的首批交换范围：attr 0–15、char 为 0 或可显示 ASCII 码 33–126（数值沿源 `strtol` 接受十进制、0x 十六进制和前导 0 八进制）。**O7 源码复核纠正**：`src/files.c:412/432` 在 char 非零时也写入 attr，因此 attr=0、char 非零表示黑色字符；`0:0` 才两项均不修改。char=0 不改字符，attr 非零仍改颜色。空格 32 不满足新版可显示字形校验；高位旧图片图块码不接受。Unicode、仅改字符而不改颜色、纯黑色覆盖但不指定字符及背景覆盖用 JSON。导出只输出可无损表达的覆盖，列明无法表达的项。

同一文件重复设置按源顺序最后一次为准；在预览中显示最终差异。`auto_get_*` 两值先从当前单选反解，再按行更新，最后 objects→Wanted、否则 ammo→Ammo、否则 Off。不能让后一个无关的 false 行错误关闭另一个模式。映射导入不自动切换当前预设。R/K 未识别编号只报告原输入与原因，不查询隐藏怪物／物品名字用于报错。

`use_old_target/auto_target` 也先从当前枚举反解为临时二值，按文件顺序修改后一次性转回：false/false→手动，true/false→旧目标，false/true→最近敌人，true/true→旧目标优先、否则最近敌人。`!` 单行修改其中一值时保留另一值的当前含义。导出枚举时完整输出这两个别名，以保证往返；不持久化临时二值。`find_ignore_*` 分别转换为停靠点是否选中，X（不忽略）加入该停靠点，Y（忽略）移除，只改对应条件。

光照布尔项、旧 graph 组合、描述缩写、敌情打扰和危险边框都不再有对应运行开关，不能通过 PRF 重新创建。导入逐行说明统一主题／图块／场景描述／敌情策略或暂缓依赖；完整新版表达通过 JSON 交换。跑步切角保留独立 `find_cut` 别名，不能当成停靠点转换。

`!` 只接受一条完整、无需文件上下文的指令；`A`／`C` 单行因缺成对上下文明确拒绝，不留下跨调用的隐藏 action 缓冲。文件的 A 缓冲仅在本次解析有效；悬空 A 或无有效 A 的 C 拒绝提交。受支持行只构造变更草案，确认前没有副作用。语法／值错误阻止提交；普通不支持项可在预览中明确选择仅应用受支持项，但条件／include、损坏的 A/C 关系不允许绕过。提交全局偏好文件失败时不应用运行态；并发修订过期时保留草案并报告冲突。
