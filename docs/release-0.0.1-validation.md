2026-09-15。用户授权提交、推送并重新发布现有 `v0.0.1`；应用版本仍为 `0.0.1`。本次覆盖此前暂缓验证的 Mogaminator、长按移动、未达等级能力预览、自动探索与物品记忆、鉴定第 1–4 步、火把堆叠、怪物配色／unique 彩虹及自然繁殖上限。

- 本批不兼容旧开发存档，应新建角色；不清理用户原有存档。

- Core 首轮全量：2,151 项通过、29 项失败、18 项显式忽略。29 项逐一修正后全部定向复验通过；之后只做两处等价条件简化以通过 Clippy，没有重复整轮测试。
- 失败修正涉及旧的穿戴即完全鉴定预期、鉴定后 feeling 清除、火把数量／格数、默认 Mogaminator 干扰，以及测试中的合法词缀品质、神器生成记录、金币 ID、楼层存储键和读档排序；没有放宽生产存档校验。
- Content 183、Contract 库及集成 17（另 1 项显式忽略）、Legacy import 223、Legacy probe 2、Localization 40、Protocol 7、Replay 13、Save 2、Tauri 36 项通过。协议旧投影测试补齐当前必需的鉴定和繁殖字段。
- 前端 470 项通过；长按测试发现普通方向键缺少映射，修正后输入控制器 138 项通过。渲染 profile 加入 unique 字符后其 3 项测试通过；最终 standalone 构建包含类型检查和 Vite 构建。
- `cargo clippy --workspace --all-targets -- -D warnings`、Rust 格式及差异空白检查通过。
- 普通 EXE 的 Mogaminator 中英文默认规则应用／随后移动通过；首次实测应用约 108 ms，移动约 246–262 ms（含 IPC 与状态读取，不作为跨机器性能保证）。

- 普通 EXE 渲染 profile 的三种分块尺寸全部通过，含 unique 彩虹字符的实际渲染、地图更新、相机移动和 tileset 切换，没有捕获到运行时异常。该项是渲染冒烟验证，未替代完整的视觉可读性及后台／减少动态效果人工验收。
