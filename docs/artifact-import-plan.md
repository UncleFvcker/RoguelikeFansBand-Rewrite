## 每批关闭条件

- **内容定义：**完整源参数、权威中文名、底材和来源记录；正式包版本与 lock 更新。仅类型变化才生成 Schema／协议，不手改生成物。
- **规则与入口：**逐件检查 flags/pval、诅咒、随机附加、激活和专属消费者；至少一个符合源规则的真实获取路径。普通池／instant／专属奖励分别取证；受控稀有度和等级前置须明示。
- **保存与唯一性：**从新角色出发，验证生成、拾取、未知状态／鉴定、装备或使用、保存后继续；覆盖本批实际随机或冷却边界。不以直接物化代替普通生成，也不为每件复制一套相同测试。
- **检查范围：**运行直接受影响的既有测试、内容与名称／来源校验、lock 和生成审计；公共 RNG 或状态输入变化再按实际范围执行全局契约。纯内容变化不自动刷新 fixture，不因普通合并重跑全 workspace。
- **交付口径：**分别报告定义、规则、入口和验收；专属桌面证据留在 I7，明确未执行的部分。需要交付可玩桌面产物时使用 Tauri standalone；既有构建或核心受控测试不替代桌面流程。

每批结束只更新当前映射、待办和长期依赖，具体完成细节放提交说明，不继续向本计划追加批次流水账。
