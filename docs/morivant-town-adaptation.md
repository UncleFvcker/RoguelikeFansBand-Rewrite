旅店餐饮独立于库存购买：按 `src/bldg.c::inn_comm(BACT_FOOD)` 设置饱食度到最大值减一，包括骷髅与已经过饱的角色，不生成物品、不推进世界时间。种族判断复用当前有效种族（包括拟态），核对 `src/cmd6.c::mortal_food_check` 与 `src/races.c::prace_is_`；保留现有正式种族的 1/3 自助餐和适用的 1/27 速度法杖提示分支，RNG 由 Rust 消耗。餐饮提示为本项目独立表述。

驯兽师按正式怪物种类提供名称、符号和唯一性筛选，不要求怪物已出现或可见。浏览、筛选、选择及关闭不发付费命令；确认研究才扣费并写入现有 `probed_actor_kind_ids`，资料可保存恢复，重复浏览已知资料不收费。来源为 `src/bldg.c::research_mon` 的确认查看边界；目前用既有探查知识表示该种类已知，没有另外增加目击次数。资料显示种类描述、等级、唯一性、基础生命值、速度、护甲、抗性、状态免疫、近战攻击与能力列表；不把种类基础生命值显示成场上实例生命值。完整原版怪物记忆中的目击/击杀统计、掉落知识、警觉、移动和其他标志尚未投影。

传闻：已核对同一提交的 `lib/file/rumors.txt` 存在中文池，`src/files.c::get_rnd_line` 负责选取原文。但该文件及仓库根目录未提供能明确覆盖此文本池再分发的许可；本批未复制传闻池，也未用传闻卷轴文字替代。依 S2 计划保持入口隐藏，待有可交付来源后再接入 Rust 随机抽取和消息事件。

其他原版职业身份保留在来源记录中，不引用尚未实现的职业 ID；接入领域身份不增加新游戏构筑入口。盗贼公会当前向正式构筑收取其他身份价格，Owner 基础价保留在内容中，待 Rogue 正式职业交付后绑定。图书馆不显示鉴定全部，战士公会不显示请求任务和神器重铸，盗贼公会不显示请求任务，王牌之塔不显示指定地牢层传送。

批量鉴定的会员报价和实际扣费由 Rust 使用同一函数计算；阿南巴图书馆原有 350 金价格不变。公会住宿复用旅店的中毒/流血拒绝、半日时间推进、资源恢复与召回取消规则，不创建公会商店库存，也不提供旅店跨城传送。

沿用现有设施计费：零声明价的武器、护甲与弓强化按 Owner 750 / 其他身份 1500 收费，弹药按数量收费。原版按物品价值增量计算强化档位、全局服务价格因子的完整算法尚未实现，本批不将基础价接入表述为完整经济系统复刻。

九类商店复用现有正式库存和交易机制；店主固定选用原版各类店主表中的第一名人类店主，名称、贪婪度与收购上限取自该条目，不实现原版店主随机轮换。Home 共用 `demo.town-facility.outpost-home` 的仓库。

旅店由凯勒波经营，住宿 20 金，前往已访问城镇 500 金。原版建筑的“半精灵”是显示字符串，当前商店模型的 `owner.raceId` 必须引用规则种族；正式包没有半精灵规则种族，因此旅店暂沿用既有旅店适配的 human 交易种族参数。此字段不表示原版人物种族已复刻。库存食品交易与 2 金餐饮服务分别开放；传闻与声望未开放。

城堡只开放任务 51「我讨厌蛇！(莫里万特)」。接取后废墟入口开放，拾取琼斯博士的鞭子后回到本城，再向布林结算；结算不另发神器。失败或放弃后入口关闭，回访显示相应结果，后续任务链保持关闭。固定神器已在其他地方生成时仍沿用任务地图的拒绝生成分支；原版替代随机神器身份机制尚未实现。

邻近探索目的地为潮汐洞穴：从世界坐标 `(47,50)` 向南，经 `(47,51)` 道路草地、`(47,52)` 草地，到 `(47,53)` 浅水。四格符号 `3/*/./_` 与上述来源提交的 `w_info.txt` 一致。浅水允许普通非骑乘战士步行，但该荒野格的遭遇等级为 40；潮汐洞穴自身深度为 15–27，不能据此推定地表同样安全。世界地图上不能直接下楼，须返回局部地图并站到实际入口；入口没有额外地表守卫，末层守卫仍使用既有定义。莫里凡特出生位置、商店与建筑门格无重合；附近世界地点只有本城与潮汐洞穴。

从洞穴根层上楼会恢复进入前的地表位置，再沿世界坐标北返即可回城补给。普通召回前往已记录的地牢层，从地牢召回则恢复本次出发的地表位置：从洞穴入口出发就回入口，从莫里凡特王牌之塔出发就回塔前，不选择最近城镇。连续荒野及其中的城镇统一按地表处理召回，倒计时允许保存恢复。城镇库存、共享 Home 与地牢实例继续使用各自既有状态；地牢重入是否重建仍由实例生命周期决定。

保留九类商店买卖、首次访问的延迟库存初始化、跨城 Home、住宿、旅店往返，以及任务接取/完成/失败/放弃各阶段的既有检查。餐饮检查覆盖骷髅、过饱、拟态和提示 RNG 分支；怪物研究检查覆盖未遇见的种类、缺少资料、入口、金币不足、浏览不变和知识保存恢复。拒绝命令仍按现有协议增加命令计数，但不扣金币、不推进世界时间或消耗业务 RNG。召回检查覆盖城镇收费启动、倒计时保存恢复、目标楼层和返回位置，并复用潮汐洞穴已有入口、召回和存档检查。城镇地图不再专门验证可达性或完整步行路线；布局问题由玩家试玩后调整。桌面画面和人工试玩不在自动检查结论内。
