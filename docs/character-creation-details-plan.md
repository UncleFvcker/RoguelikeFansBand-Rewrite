## 2. 当前缺口和复用路径

- `web/index.html`、`web/src/character-creation.ts` 已有概览、种族、职业页面，多级目录及右侧候选项说明；候选预览与已确认选择已分离。复用这些交互，不重建选择器。
- 目前详情主要是名称、介绍和部分专项提示，缺少组合后的六维、生命／经验修正、技能评价，以及来源分解。
- 内容定义已有种族、职业、性格修正、生命／经验百分比、基础 HP、技能基础／成长、抗性与等级特性。构筑持有初始属性和性格 ID，例如战士构筑使用普通性格。
- Core 的 `game/progression.rs` 已计算组合属性、技能、经验与生命；`game/trait_details.rs` 已提供游戏内特性明细。仅抽取本次需要的纯计算供两处复用，不把整个游戏内详情 DTO 强塞给尚未创建的角色。
- 当前 `initialize_game` 没有只读创角预览入口。新增小型预览投影，禁止浏览候选时调用正式初始化、生成地图／商店、消耗 RNG 或写存档。

## 3. 页面安排

沿用当前创角外框、主题和固定页脚，扩大详情区的信息密度。宽屏选项列表在左，右侧为候选组合明细；概览页复用同一份明细展示已确认组合。

```text
创建角色                         概览 / 种族 / 职业
已选：姓名 · 种族／亚种 · 职业／领域 · 当前性格
──────────────────────────────────────────────────
分类与选项             正在预览：候选名称
                       简介、关键优势与限制
                       六维：基础｜来源修正｜最终值
                       生命修正 · 基础 HP · 所需经验倍率
                       八项技能评价（每行四项）
                       初始特性 / 随等级获得 / 详细来源
──────────────────────────────────────────────────
已确认组合摘要                       返回 / 开始游戏
```

### 数值显示

1. 六维使用紧凑表格，默认展示基础、修正合计和预计最终值；展开查看种族、职业、性格来源。遵循 Core 的属性步进及 `18/xx` 格式，不能做普通整数相加。施法主属性明确标识；无施法属性的职业不显示假默认。
2. 生命修正用百分比，基础 HP 明确表示构筑提供的基础贡献；不冒充随机成长、体质和装备结算后的实际血量。经验使用“升级所需经验倍率”，说明高倍率一般升级更慢；特殊经验机制按实际规则说明。
3. 技能显示原版文字评级并辅以颜色；展开可看基础和成长的来源。评级不是概率，不用虚假的百分比进度条。当前额外的投掷、挖掘信息可放详细项，不声称是原版创角八项之一。
4. 仅在当前数据足够且可复用真实计算时显示开局预计 HP／MP；不能可靠得到的数值不伪造。第一批以修正、基础贡献和技能为交付范围。

### 浏览和比较

- 焦点或鼠标浏览具体叶子时，用候选种族／构筑加上其余已确认选择计算预览，显示相对当前组合的数值变化；激活叶子才确认。已有明确优劣含义的数值才用增益／减益色。
- 分类、职业父节点或未完成的领域分支只显示类别说明，不暗选第一个子项生成貌似完整的角色。
- 快速切换时只接受最新候选的响应；预览失败显示明确状态，不将上一候选的数值挂在新名称下，也不改动草稿。
- 仍由 Core 校验组合；前端不得仅靠能显示预览便认定能开局。
- 保留方向键浏览、Enter／Space 确认、Esc 返回以及 Tab 焦点导航；不采用原版 Tab 翻统计页而破坏现有可访问性。
- 窄屏继续使用选择／说明切换，贡献表可展开；固定姓名摘要和开始入口，避免四栏硬挤或整页无限增高。

### 特性详情

分成“初始拥有”“随等级获得”“限制与代价”。包含实际实现的抗性／免疫／弱点、红外视觉等感知能力、饮食或装备限制、施法方式、职业能力及解锁等级。

自动获得、达到学习资格、需要书籍或其他条件必须区别标注。未来能力可以显示，但不能把尚未实现的内容描述为可用。现有静态说明用于解释背景；数值与等级门槛来自 Core／正式定义，避免再维护一份前端规则表。当前性格先只读展示，不新增性格选择入口。

## 4. 分批实施

### 第一批：核心数值能看见

- 增加只读创角预览 DTO 和 Tauri 查询，复用实际属性／技能／生命／经验组合规则。
- 在概览及具体候选的详情区接入六维表、生命／基础 HP／经验指标和八项技能评级；展示当前性格及施法属性。
- 同批处理无完整候选、查询失败、异步过期响应和确认状态，确保看到的数字属于当前标题所指的组合。
- 交付标准：无需创建角色，就能比较已有种族与职业组合；没有初始化副作用，没有前端重算游戏规则。

源码落点：`game/creation_preview.rs` 读取正式定义，复用属性步进、技能成长、生命和经验倍率计算；初始化与预览共用出生组合校验，变身和读档的原有解析语义保持不变。Tauri 提供独立只读查询，不访问活动会话或存档。`web/src/creation-preview.ts` 在概览、种族和职业详情间展示当前候选，区分加载、未完成选择和错误；重复焦点不重复请求，旧响应不得覆盖新候选。

预览明确排除装备、开局随机效果及临时状态；基础 HP 是来源贡献，不是最终血量。当前性格随组合显示，施法属性来自职业配置；机器人经验机制另行说明。没有新增配点或性格选择。

相关用例已通过：Core 的 `creation_preview::tests`（实际新角色数值、组合边界、原版评级阈值），前端 `creation-preview.test.ts`（响应次序、重复焦点、未完成选择、退出、失败与重试），以及共享属性计算直接相关的 `attribute_sources`、`progression::tests`。

**协议生成**：2026-09-16 已运行 `cargo run -p rfb-protocol --features bindings --bin generate-bindings`，同步 `web/src/protocol.ts` 和 `schemas/protocol-v1.schema.json`，生成一致性与前端类型检查通过。创角测试改用正式默认行为偏好函数初始化新角色。

### 第二批：来源、特性与成长信息

- 展开种族／职业／性格贡献，加入候选相对已选组合的差值。
- 接入初始特性、随等级获得的能力和重要限制，区分自动获得与条件解锁。
- 调整说明层级与留白，使数值和重要限制优先可见，长背景说明与完整来源可展开。
- 交付标准：玩家能回答“为什么是这个数值”“这个选择有什么代价”“升级后获得什么”。

源码已接入：

- 展开三类来源的六维、生命／基础 HP／经验定义，以及八项技能的基础和每十级成长。特殊经验机制有说明，避免将机器人职业经验倍率误认为实际参与结算。
- 比较对象始终是已确认组合。属性用原值→候选值保留 `18/xx` 语义，生命／经验显示百分点差，技能显示基础／成长差；候选确认后差值消失。比较对象无法预览时保留候选，并明确说明无法比较，不伪造基准。
- `game/creation_traits.rs` 从正式定义投影抗性、免疫、感知、维持属性、种族及职业能力、等级天赋、施法学习方式、负重和重要装备／饮食限制。常驻特性与主动能力的使用条件分别标示；机器人能力标出阶段结束等级。牧师／圣骑士能力按已选领域筛选，与实际调用共享资格函数；狂战士、心灵术士被动及狂战士状态免疫共用解锁表。
- 法术显示书籍学习或祈祷学习的资格说明，不将“达到施法起始等级”说成学会全部法术；本批没有生成每一条书本法术的等级表。特殊种族的墙内伤害、饮食、护甲等说明复用已审计文本，背景完整说明仍可展开。
- 重要限制默认可见，来源、未来成长及长效果说明可展开；原背景段落折叠。种族／职业页的 Enter 不再拦截原生 summary 操作。受影响桌面脚本在检查长说明前显式展开背景。

新增覆盖已通过：来源与合计对应、狂战士归还／免疫等级、机器人能力替换区间、牧师学习方式与领域筛选；前端覆盖已选基准、确认后移除差值、基准失败、来源展示及条件分类。共享资格与被动规则的牧师、圣骑士、狂战士、心灵术士对应既有用例，以及特性明细用例已通过。完整创角桌面脚本尚未执行，本批普通 EXE 仅进行下述聚焦烟测。

## 5. 实施边界与验证计划

新增投影类型按项目流程生成协议绑定／Schema，不手改生成文件。纯预览不改变存档状态、RNG 或状态哈希；仅展示已有定义不升级内容包。若确需导入缺失说明或来源数据，另按内容流程更新版本、lock 和来源记录。

获准验证后按真实影响选取：

- Core：预览与同一构筑的实际属性、技能及经验修正一致，覆盖属性步进、特殊经验机制与无施法职业；确认预览不改变游戏状态或同种子的开局结果。生命基础贡献与最终 HP 分开断言。
- 前端：候选与已选分离、未完成分支、快速切换响应顺序、错误提示、确认／取消和最终创建参数。复用现有会话及创角测试，不为每个菜单叶子复制测试。
- 相关协议生成检查与前端类型检查；用户要求试玩构建时使用 Tauri standalone。
- 聚焦桌面创角脚本：普通近战、施法、多级亚种／领域及特殊限制的代表组合；检查明细布局、键盘、缩放和新角色实际数据。不使用旧开发存档。

计划阶段仅核对代码、原版来源和文档差异；没有运行上述编译或测试。
