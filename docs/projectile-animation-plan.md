# 远程攻击动画

## 第一批：箭矢、投掷物与 bolt

源码已接入；本轮验证范围见文末。

- 普通射击、穿透／连射的每次实际发射、普通投掷，以及直接 Damage、共用定额伤害 bolt 和 bolt-or-beam 的实际 bolt 分支，新增成对的 `animation.projectile-start/end` 展示事件。沿用 `GameEventDto` 的 kind／args／trace 扩展，不修改协议类型、存档、RNG 或伤害规则。展示事件不进入消息记录。
- 起止事件明确区分同轨迹连射和单支穿透箭的多目标命中。命中／死亡事件在本次飞行内合并；嵌套触发的弹体在父弹体到达后播放。反射沿现有反射事件的真实返回轨迹播放，尚不额外投影反射命中目标的身份。
- 箭矢沿轨迹转向，投掷物使用物品外观；bolt 使用元素色字符与短尾迹，颜色遵循当前调色板。飞行按实际 traversed／impact 插值，不把弹药落地位置当成撞击点。
- 显示期间读取最新核心可见格，建立特效专用硬遮罩，避免尾迹透过记忆迷雾。命中提亮、击杀淡出复用可见目标外观；模糊感知及未知怪物不生成残影，残影不参与目标选择或交互。
- 箭矢／投掷物飞行约 80～200ms，bolt 约 100～220ms，命中淡出约 80ms；连射短间隔错开，整批飞行跨度封顶 320ms，连同收尾最多约 400ms。复用现有动画完成等待，快速独立操作结束旧显示后接续，不积压待播动画。
- 特效位于地图坐标层，随镜头、缩放与视野同步；不增加远程镜头震动。快照、换层、玩家移位、后台、减少动态效果、换图和销毁停止／清理显示。核心本次结算已导致死亡或换层时不播放旧场景弹体。

已补前端分组、穿透、空射／撞墙、嵌套／反射、插值与可见性用例；消息记录验证起止事件不生成行；核心补空射起止／RNG 用例，并扩展已有穿透测试检查单发边界。相关自动测试与 standalone 构建已通过，实际桌面动画观感尚待逐项验收。

## 第二批：beam 与 ball

源码已接入；本轮验证范围见文末。

- 共用 beam 执行器、随机 bolt-or-beam 的实际 beam 分支和共用 area 执行器补齐展示起止事件；复用已有 `ability.beam-damage` / `ability.area-damage` 的受影响格与爆心投影，不增加协议类型或改动伤害、阻挡和 RNG。
- beam 沿真实轨迹约 60～100ms 展开，保留已展开的元素色外沿和细白亮芯，随后约 80ms 消退。一次光束穿过多个目标仍只画一束，命中反馈按已知怪物位置安排，不误用共用 trace 的终点。
- ball 沿真实轨迹飞到核心爆心，再用约 110ms 从爆心向实际受影响格扩散，每格亮点与元素光斑约 80ms 消退。撞墙时爆心采用核心 landing，自身中心爆炸直接扩散；不补画圆形范围，不显示核心未纳入的墙后格。
- 共用现有调色板、可见格硬遮罩、完成等待与清理。每格只有短时 Graphics 图形，没有独立粒子对象；扩散到达时刻在启动时计算。多个球和嵌套效果保持分组，时间压缩同步作用于飞行、扩散和命中，整批仍约 400ms 内收尾。
- 补充核心墙边面积／光束投影边界与 RNG 用例，并扩展原随机 beam 测试；前端补充光束多目标、墙边爆心、实际扩散格、自身中心、多个爆心及压缩后时序同步用例。相关自动测试与 standalone 构建已通过。

## 第三批：storm、陨石群与重叠控制

源码已接入；本轮验证范围见文末。

- 核对当前正式 abilityPrograms 与执行器：法力风暴、自然三种风暴、心灵风暴、黑暗风暴、地狱风暴均走一次范围伤害。核心按已核对的稳定身份标记 `storm`，前端表现为飞行／展开、短暂涌动、消退；不按名称子串猜测，也不添加回合或伤害脉冲。自然之怒共用 area 分支、法力风暴法杖和盗窃黑暗风暴复用相同样式，其余结算保持原状。
- Chaos／Trump 的 `ChaosMeteorSwarm` 执行器实际使用多个 `PROJECT_JUMP` 落点。核心按此效果类型标记 `meteor`；仅在真实落点上方做短落下演出再扩散，不绘制角色到爆心的水平路径。每次核心实际爆炸保留自己的中心、影响格和命中反馈。
- 取消第 4 次之后统一挤在 80ms 的错峰上限；整批统一压缩，保留各次先后和嵌套相对时序，仍约 400ms 内完成。storm 涌动是单次伤害的短展示，后续真实施法／伤害事件才会产生下一次动画。
- 重叠范围每格仅绘制当前最强的一份底色，保留全部可见影响格；装饰亮点／旋弧每帧最多 128 个，不创建逐粒子 Sprite。相同怪物的重叠命中闪光取最新一次，击杀残影去重。沿用后台、减少动态效果、换层与销毁清理，以及视野硬遮罩。
- 补充 storm 一次命中／涌动／消退、20 个陨石落点与错峰、重叠绘制去重用例；扩展现有法力风暴与陨石群核心测试，检查展示边界并保留原伤害、中心、地形及重放断言。相关自动测试与 standalone 构建已通过。
