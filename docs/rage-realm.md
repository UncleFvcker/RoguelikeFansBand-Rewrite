# 狂怒领域与狂怒法师

来源为 RFB `master` Git 对象，提交 `a0d92b6378d148c5262cc236b8fa6ed2ca06a54c`。本批核对 `ragemage.c`、`spells.c`、`effects.c`、`xtra1.c`、`xtra2.c`、`cmd1.c`、`spells1.c`、`gf.c`、`monspell.c`、`object2.c`、`object1.c`、`artifact.c`、`ego.c` 及职业、书本中文表。32 个槽位和源等级／费用／失败率保留在正式包 [来源记录](../packs/rfb-demo-original/legacy-rage-source.json)。

## 内容与入口

新增 `demo.class.rage-mage` 与 `demo.build.rage-mage`，创角入口为“近战 → 狂怒法师”，固定狂怒领域。力量施法，采用源职业属性、技能成长、武器熟练度、护甲惩罚及法力容量加成；出生装备为正式阔剑与软皮甲。

四册 source kind 564–567、tval108 进入完整普通生成池，前两册进入书店。每次研读只学习选定的一招，并消耗一本书；已经学会的招式不再要求携书，不能通过重复研读提高熟练度，也不能手动遗忘。书本来源、中文显示名及分配行由源表同步。

## 规则与消费者

- 法力不自动恢复。每次玩家行动损失 `(当前法力/8 + 等级/10 + 1) × 能量/100`，全部按原版整数顺序取整。对怪物造成正伤害回蓝，狂暴中比例提高；受到伤害根据受击前生命比例回蓝。造成伤害与成功专注狂怒会跳过一次行动衰减。该标志进入存档与状态哈希。
- 专注狂怒及高等版本以生命换法力，失败仍扣生命；狂怒打击根据施展前全部法力计算伤害，再扣 100 生命，非狂暴时施加震慑，成功／失败均清空法力。界面在提交这些自伤招式前确认。回蓝物品对本职业无效，勇气药水把至多 200 法力换为治疗。
- 狂暴不禁止狂怒招式；反魔法仍禁止施展。探测魔法敌人、规避跳跃、元素抗性、召唤部落、原力附魔及反魔法相关招式使用各自的狂暴增强。狂暴规避跳跃耗 30 能量。
- 怒吼使用实际声音锥形投射；强力打击执行一次正常武器攻击、击退与碰撞伤害；旋风攻击复用周围真实近战。法力碰撞按怪物施法频率缩放，非施法者不受伤害。
- 反魔法射线经过力量豁免，失败时压制怪物非天生施法；法术反转按源概率将伤害投射沿来路返回。狂怒护甲在实际法术伤害后对施法者判定力量豁免，执行减速与震慑。法术反应在已接入的骚扰类法术后提供短暂加速。
- 粉碎装置接受背包或脚下地面装置，不要求已鉴定或尚有充能，消耗整个实例。根据真实激活效果处理无效果、破坏地形、恢复、放逐及周围爆炸；伤害取激活难度的 16 倍。当前正式装置的元素、无效果和破坏等分支可达；未导入的装置身份不因分支存在而记为已验收。
- 映图、照明、饱食、英雄状态、解除附魔抗性、阻止繁殖、鉴定、地震、驱散诅咒和怪物增益驱散复用对应消费者。地表地震保留原版付费无效果分支。黎明战士是已有正式怪物，作为永久受控同伴召唤；狂暴召唤附带 100 回合加速。

普通／优质生成保留所有合格书本；Good／Great 对狂怒法师的高阶书发现上限为八次，Tailored 狂怒书同样要求发现数小于八。狂怒法师始终需要书，先抽职业的 1/3 书本偏好，未命中再抽共用 1/10；不获得装置职业偏好。生成适用性记录同时覆盖普通装备、Ego、随机神器与固定奖励。源 Stress Ball 的专属激活依赖尚未导入的神器，本批没有开放该物品。
