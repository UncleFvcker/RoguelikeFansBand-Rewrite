## 查阅方法

按机制名、来源索引或原文件名定位一份相关材料，再核对当前代码。相对 Markdown 链接已按移动位置调整；文中的 Git 提交、代码片段和当时路径保留其历史含义。历史指向的已退役代码或 fixture 不会为修复文档而重建。

不要重新执行旧文档里的迁移/刷新流水线、恢复旧分支，或把历史“未实现”直接变成当前任务。需要补充新的事实时更新当前指南或提交说明，不回写这次归档快照。
