# 2026-09-09 可玩版本验收

本次把已完成的测试收敛工作与桌面验收修正固化为本地提交，再从该提交执行 `cd web; npm run build -- --no-bundle`。发行产物使用 Tauri release 构建，嵌入前端资源；不依赖 Vite 开发服务器，不包含 WebDriver。
