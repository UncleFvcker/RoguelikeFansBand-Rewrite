# 标题页面改版计划

状态：初版标题页与后续三维地牢入口均已完成相关编译和专项验收。3D 背景已进入 `target/release/rfb-tauri.exe`，纳入 v0.0.2 同版本重新发布。

本批 3D 改动限定于 `web/src/title-background.ts`、标题背景 CSS 与现有专项验收脚本。沿用大标题、菜单、版本与存档摘要；3D 本批结果与初版验证分别记录如下。

## 当前背景：三维地牢入口

- 在现有 Pixi 全屏滤镜中，用透视射线步进三维距离场生成石砌入口，不新增 3D 引擎、模型资产或游戏地图状态。
- 稍偏轴的固定镜头看向石拱门，门内连续拱肋与六级下行台阶形成纵深。石材使用程序化砌块、拱顶径向石缝、颗粒与少量苔色；表面法线、局部遮蔽与距离衰减提供体积感。
- 冷色环境光与暖色火把并置，门内逐渐变暗；火光轻微起伏、雾缓慢流动，镜头保持稳定。左侧菜单遮罩保留，窄屏将入口重心移向中央。
- WebGL／WebGPU 使用相同几何与光照表达。移除旧 GPU ASCII 文字纹理，GPU 失败时保留静态 ASCII 拱门与原菜单。
- 每条射线最多 72 步，最远 24 场景单位；背景内部像素上限 960×600，最大比例 0.6，沿用 30fps 上限、失焦／隐藏暂停与减少动态效果静帧。这些是成本限制，不代表跨设备帧率保证。

### 3D 相关验证（2026-09-15）

- 用户授权后执行 `npm run build -- --no-bundle`：类型检查、Vite 和普通 Tauri standalone 构建通过；未创建 NSIS。
- `node web/e2e/title-standalone.e2e.mjs` 的 10 组检查通过，无未捕获异常。实际使用新的普通 EXE 副本、独立 WebView 目录与新角色存档，全局偏好保持不变。报告 `test-results/title-screen/report.json`。
- WebGL 程序链接与实际绘制通过；WebGPU WGSL 在实际 adapter 上通过编译，未验收 WebGPU 完整场景。
- 四种窗口尺寸均无横向溢出、六个按钮可达；背景尺寸满足 960×600 上限。已查看 1920×1080、1280×720、390×844 截图：入口、火把和拱肋纵深可见，深处地面隐入暗处，菜单保持可读。
- 原生键盘导航／Enter／Space、设置／高分榜／读档入口、新建角色／保存／继续加载及摘要一致、原生退出通过。创角、减少动态效果和模拟失焦时绘制计数停止；主动注入 WebGL 上下文丢失后静态入口与读档菜单可用。
- 活跃窗口 1.6 秒采样为 94 次 GPU draw call；这是活动检查，不是 GPU 帧时间基准。没有复跑未改变的 164 项单测，也未跑全量前端／workspace／规则／契约测试。

## 初版目标与方向（已验证基线）

标题页以 **RoguelikeFansBand** 为唯一主标题，采用古典奇幻与 ASCII 地图相结合的视觉。用户认可大标题、纵向菜单与整体构图，并要求颜色不固定黑金、背景采用动画 shader。视觉变化适中、背景持续缓慢流动、信息密度低；设计参数为 DESIGN_VARIANCE 6 / MOTION_INTENSITY 4 / VISUAL_DENSITY 3。

保留现有原生 HTML／CSS／TypeScript 和按钮事件，动画复用项目已有 PixiJS，不引入组件库、动画库或在线字体。标题是可选择、可缩放的真实文字，GPU 背景独立置于其后。

## 改版前的情况

- 当前 `.session-card` 最大宽度为 48rem，居中放置在全屏背景上；高分辨率下内容显得过小、四周缺少构图。
- `session-heading` 仍为“进入兽穴”，`session-eyebrow` 仍显示 `PHASE 17 / 完整玩家旅程`，没有游戏品牌标题。
- 三个主要操作横排，设置与退出字号和位置较弱；蓝色卡片与游戏内黑金风格不统一。
- 标题、创角、读档共用 `.session-card`，后两者已有独立布局，标题样式应限定在 `data-view="title"`。
- 现有入口包括新游戏、继续游戏、读取存档、高分榜、设置和退出。继续游戏已有有效手动存档过滤；摘要已有角色名、等级、地点与保存时间，无需新增核心投影。

### 标题与字体

- `RoguelikeFansBand` 保持准确拼写和完整可读，桌面字号约 64–104px，按可用宽度约束，取消现有 `max-width: 14ch` 的标题限制。
- 英文标题使用本地衬线字体（Georgia 系列）营造古典感，颜色取界面主文字色，以当前强调色形成轻微轮廓光；不使用描边堆叠、整字霓虹或彩虹效果。
- 下方仅放小号、适当字距的 `REWRITE`。中文菜单使用现有界面字体；ASCII 背景使用现有等宽字体。
- 移除标题区域的“进入兽穴”、`PHASE 17` 和“完整玩家旅程”等开发阶段标记。浏览器标题文案同步统一为 `RoguelikeFansBand Rewrite`。
- 游戏内真实兽穴地点、地形和行动名称不属于本次标题文案替换范围。

### 背景与颜色

- 不锁定黑金。背景采用可调色板，首版以深蓝、青绿与灰紫的低饱和光雾缓慢交融；最终色相可调整，不新增配色预设菜单。文字、按钮和焦点继续取现有界面颜色变量，背景在文字区域以界面底色遮罩降低干扰。
- 右侧以 `# . + > @` 等字符组成抽象遗迹、道路和冒险者轮廓，向边缘淡出。它是装饰，不代表玩家当前存档、指定地牢或游戏地图。
- 保留大面积干净的暗部，菜单背后不铺复杂字符。背景不拦截鼠标，不参与键盘焦点和屏幕阅读器内容。
- 去掉标题页的蓝色圆角卡片和厚重投影；菜单以文字、细线和选中标记形成层级。

### 动画 shader

- **远景光雾**：低频噪声缓慢平移和变形，约 25–45 秒形成一次明显的构图变化；避免快速旋转的漩涡、强闪光和满屏高饱和渐变。
- **ASCII 遗迹**：保留字符轮廓，用流动光照让道路、墙体和冒险者逐渐显现；字符位置稳定，不逐帧随机替换或模拟实际游戏。
- **局部光照**：让背景中的少量光点缓慢呼吸，亮度变化周期约 8–12 秒；光雾在遗迹后方经过，形成前后层次。第一版不增加鼠标追光和视差。
- **阅读区域**：标题、菜单及存档摘要保持稳定，光照主要集中在右侧和边缘；背景变化不能导致某一帧按钮文字难以辨认。
- **实现路径**：新增一个职责明确的 `web/src/title-background.ts` 管理标题背景、静态 ASCII 纹理和单个 Pixi 滤镜。参考 `unique-rainbow-filter.ts` 已有的 `GlProgram`／`GpuProgram` 写法，提供对应 WebGL／WebGPU 程序；只复用技术方式，不套用 unique 的彩虹效果或游戏地图渲染器。
- **更新成本**：每帧仅更新时间等 uniform，不重建文字、纹理或 DOM。尺寸与色板只在变化时更新；背景按较低内部分辨率渲染，初始目标约 30fps、像素比不超过 1，标题和菜单仍以原生分辨率显示。这是实现预算，尚未测量性能。
- **生命周期**：仅标题可见时运行；进入创角、读档、游戏或窗口失焦／页面隐藏时暂停。回到标题后继续，销毁时移除监听并释放 GPU 资源，避免后台常驻动画或重复创建上下文。
- **减少动态与 GPU 失败**：减少动态效果时固定画面并停止 ticker。GPU 初始化或上下文失败时保留静态 ASCII 与底色，记录错误，现有新游戏和读档入口仍可用，不循环重试初始化。

### 菜单与状态

- 保留六个入口和现有 ID。纵向顺序为新游戏、继续游戏、读取存档，然后用间距分开高分榜、设置、退出。
- 菜单文字约 20–26px，点击行高至少 44px。悬停或键盘聚焦时显示当前强调色、左侧指示符与很淡的背景；未选中项仍有充分对比度。
- 有有效手动存档时，初始焦点落在“继续游戏”；没有时落在“新游戏”，继续项禁用并标明“暂无可继续的存档”。存档列表刷新不抢走用户已移动的焦点。
- 继续项下方显示最近可继续存档的角色名、等级和地点；可用时补充保存时间。直接复用继续操作所选择的同一摘要，恢复点不冒充可继续的手动存档，未知字段不编造内容。
- 正常状态不再强调“找到 N 个可用存档”。读取中和失败原因仍在菜单附近明确显示，保留原有忙碌禁用、错误展示与重试入口。
- 保留 Tab／Shift+Tab、Enter／Space 的原生按钮操作；仅在标题菜单中补上下方向键导航，跳过禁用项，不影响创角、读档和弹窗。
- 版本位于页脚，取构建中的应用版本，禁止长期硬编码 `0.0.2`。页脚另一侧显示简短键盘提示。

### 动态与尺寸

- 初次显示可用约 200–300ms 的整体淡入；菜单反馈约 120–160ms。标题保持稳定，背景按上述 shader 方案持续动画，不启动游戏规则或随机生成地图。
- 尊重减少动态效果设置；忙碌时禁止重复启动或加载。
- 1920×1080／2560×1440：大标题和菜单组成完整画面，不缩在页面中央。
- 1280×720／矮窗口：先减纵向留白和装饰面积，六个操作均可见，反馈较长时允许页面滚动。
- 390px 窄屏：单列菜单居中，装饰退到后方或隐藏；标题最多在 `Roguelike` 与 `FansBand` 间有意换行，保持完整名称，不产生横向滚动。

## 实施顺序

1. **结构与文案**：调整 `web/index.html` 的标题区域，更新中英文 `ui.ftl`；保留原有六个操作与创角、读档入口。
2. **视觉与尺寸**：在 `web/src/styles.css` 中限定标题页布局、字体、菜单焦点、装饰与窄屏规则，不泛改共享 `.session-card`。
3. **状态与键盘**：在 `web/src/session-shell.ts` 复用最近可继续存档摘要，补初始焦点和菜单方向键；沿用现有加载、退出和错误处理。应用版本使用构建元数据，不新增 Rust 游戏状态或协议字段。
4. **动画背景**：实现独立 Pixi shader 背景，接入标题可见性、窗口焦点、尺寸、颜色与减少动态效果变化；异步初始化完成后仍须核对标题是否可见，避免离开标题后才启动动画。
5. **等待统一验证**：用户明确说“编译验证”后，再选择相关检查及普通 standalone 验收；实施期间不运行编译、类型检查、测试或桌面验证脚本，包括实际启动 shader 做运行验证。

## 验证范围清单

- 新角色、继续、读取、高分榜、设置、退出六个入口；创角和读档返回标题后焦点合理。
- 无存档、有手动存档、只有恢复点、损坏或可恢复存档、读取失败及忙碌状态；显示摘要与继续目标一致。
- 鼠标、Tab、方向键、Enter／Space，弹窗输入隔离；切换语言后文案与辅助说明正确。
- 宽屏、720px 高度、390px 窄屏、字体放大和减少动态效果；文字可读、操作可达、无横向溢出。
- shader 在所支持后端上的编译与运行、全周期文字对比度、不同界面配色、低分辨率背景的字符清晰度；记录实际帧时间和输入响应，不提前承诺帧率。
- 反复进入／离开标题、窗口失焦／恢复、减少动态效果、GPU 初始化失败与上下文丢失；动画正确暂停，资源不重复积累，失败时菜单仍可操作。
- 复用会话外壳及相关界面覆盖，最后验证实际 Tauri standalone；不以静态外观代替入口验收。
