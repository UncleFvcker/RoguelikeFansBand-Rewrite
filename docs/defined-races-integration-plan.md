## 共用实施与验收约束

- 规则、状态、RNG、费用与准入由 Rust `Game` 决定，前端展示投影并提交选择。复用现有初始化、属性、天然攻击、物品使用、升级选择和状态保存路径；没有实际需要不新增统一种族管理器。
- 沿用 `races/`、`skillSets/`、种族能力的稳定 ID 和既有 importer 来源入口。中文名称逐字采用来源，例如迈雅的“未启蒙／启明／堕落”；新能力未找到权威名称则记录 unresolved，不自行翻译。
- 每批前四步保持正式包的 `rfb-compatibility` 和创建菜单关闭。需要真实初始化测试时，只在测试内容副本加入准入标签；不能以修改正式包绕过未完成状态。
- 第五步同时更新核心准入、创建目录、限制说明和直接相关前端测试。对当前 14 职业各选一个合法代表构筑运行真实出生检查；原版禁止的组合验证核心拒绝和 UI 一致，领域差异仅扩展到实际受影响组合。不复制全部种族×103构筑静态矩阵。
- 每批检查来源中的本体身份、当前形态、永久转化三个语义。保存恢复后继续执行关键动作，核对资源、装备、待选状态和后续 RNG；不用旧开发存档兼容掩盖新状态问题。
- 生成侧核对身体槽位、装备/装置可用性、奖励、自动拾取/销毁和现有生成审计中的身份依赖。种族开放不自动产生新 Build；若改变审计输入则按[内容开发](content-development.md#职业与领域-build-的生成接入)重生成报告并运行 `node scripts/audit-egos.mjs --check-applicability`。
- 每次内容变化更新正式包版本和 lock；实际类型变化才生成 Schema/协议绑定。状态哈希输入、公共初始化或 RNG 改变时按影响做全局契约检查，纯内容变化不升级哈希 Schema，也不批量刷新无关 fixture。
- 复用直接受影响的既有测试，只补真实行为缺口。五步完成时用 Tauri standalone 验证创建、代表操作、原生保存加载；高等级和物资可用显式测试准备，报告必须区分准备与自然获取。普通构建不得暴露测试准备接口。遵循[验证与契约](testing.md)，不附带 Android 或无关全量验收。

## V：吸血鬼五步

来源主入口：`src/races_k.c:1163–1233`；关联出生、饮食、世界光照、吸血和生命力路径。当前主要实现与证据：[Race](../packs/rfb-demo-original/races/vampire.json)、[吸血鬼测试](../crates/rfb-core/src/game/tests/vampire.rs)、[永久转化专项](life-force-race-change-audit.md)。

1. **V1 来源与差异核对。** 对照普通吸血鬼，避免混入怪物吸血鬼进化或临时吸血鬼领主规则。核对夜间出生、黑暗卷轴、固有照明、非生物/不死、美德、同族召唤，以及本体与当前形态各自的消费点。盘点已有测试，形成实际剩余项。
2. **V2 补齐出生与生存供应。** 加夜间出生；原版非狂战士获得 2–5 张黑暗卷轴，狂战士不获得。核对口粮、光源和职业装备的组合顺序，保留已有日照/灯光/黑暗区域、药水与吸血营养规则。用真实角色验证出生物资和可达补给；不能靠测试常驻黑暗或无敌才能生存。
3. **V3 核对能力与关联消费者。** 复用 2 级吸血，验证 1/2 级解锁、目标生物性、费用/失败、生命力与 HP 恢复顺序、饱食边界、临时形态及永久转化。只修本轮发现的缺口，保留现有光照、恢复与不死豁免覆盖。
4. **V4 保存与职业差异收口。** 验证原生夜间新游戏、白天/灯光伤害与黑暗庇护后的保存继续行动；补狂战士无法读卷轴、无 SP 职业能力支付等实际分支。按共用约束完成合法职业出生、生成/自动消费者和契约检查。
5. **V5 开放与桌面交付。** 放入不死分组并说明饮食、光照与吸血规则。桌面覆盖战士出生、黑暗卷轴、吸血和保存恢复；狂战士另验出生物资及能力入口差异。高等级和日照边界沿核心证据，不声称自然练级完成。

完成条件：原生吸血鬼能从正常新游戏开始使用自身生存手段，且保留原版光照代价；不是只有变身路径可用。

## D：变形怪五步

来源主入口：`src/doppelganger.c` 的 `mimic_race`、`_forms`、`_mimic_spell`、`mimic_upkeep` 和 `mimic_no_regen`；关联当前形态、升级天赋、变异、装备、商店及自动规则。

1. **D1 完整形态与身份审计。** 逐项核对来源形态表的解锁、失败率、费用及全部实际目标规则。明确本体种族、主动模仿形态、限时法术形态的优先级，以及哪些升级/种族效果不能由变形怪取得。列出每个当前可达缺口，不以已有出生入口等同于形态消费者完整。
2. **D2 补形态依赖与切换状态。** 完成半神形态必要前置，核对人类天赋、兽化人变异等特殊转换；用现有状态表达能力不足时，只增加主动模仿所必需的状态。接入恢复本体、装备槽变化和经验系数重算，保证物品不丢失、不复制，退出形态清理实际应失去的能力。
3. **D3 实现模仿、消耗和维持。** 初始费用来自形态经验系数 `/ 5`；维持费用按来源阈值，追踪实际世界周期调用。SP 不足以 HP 支付，失败、取消、不足、资源恰好相等各按源行为处理。主动形态切换前先恢复本体；限时形态的干扰、恢复抑制和维持中止走同一权威规则。
4. **D4 跨形态消费者与保存。** 验证人类/兽化人天赋变异、装备适配、不死补给、日照、穿墙、商店价格、美德/经验、本体特有禁用和自动拾取条件，代表形态只取自来源允许表。核对主动形态与限时形态覆盖、结束、保存恢复以及无法维持时的装备和地形状态；不能为规避非法状态自动传送或改种族规则。
5. **D5 完整菜单与桌面交付。** 按原版分组开放创建，模仿菜单由核心投影解锁/费用/失败率/不可用原因。桌面验证选择、取消、停止、维持与原生保存加载；准备高等级覆盖炎魔、半神、吸血鬼、幽灵代表。只有形态表中全部可达目标及特殊消费者均闭合，才标记变形怪完成。

完成条件：模仿具备完整代价和身份切换语义，整个来源形态表可用；不能以裁剪形态表或统一普通变身效果替代。
