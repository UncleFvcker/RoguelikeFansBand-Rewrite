## 仍未完整对齐的部分

第 1 步代码已实现，尚未编译或执行测试。实例 `known_flags` 与 ego／固定神器共享 lore 已接普通鉴定、完全鉴定和属性投影；单个已学旗标只公开对应属性，身份未鉴定时不借共享 lore 暴露 ego。固定神器随机额外属性留在实例；生成 ego 的额外属性沿用已物化的 rolled 属性来源，诅咒 biff 的 intrinsic 属性不会通过普通学习混入 ego 共有属性。完全鉴定未诅咒 ego 时记录实际观察到的随机可能属性。原有整组词缀字段暂保留为已有完全认知标记，新增逐旗标入口不通过它学习整组属性。

保存记录共享 lore、实例旗标与已知激活 profile，校验引用、旗标和重复实例旗标。合堆比较实例旗标，拆分复制知识；馆藏只随物品转移已知属性，不转移捐赠角色的全部 lore。遗忘参照 `effects.c::_forget/lose_all_info`：遗忘尚未完全鉴定的随身物品身份，保留旗标、祝福／诅咒知识和共享 lore；Ty 诅咒及混沌牌遗忘复用同一入口。平凡化清除失效实例知识，已有共享 lore 留存。

激活效果在存档中使用现有稳定 profile ID；不同 profile 通过导入器已有的相同源效果 name key 识别同一效果类型，不比较翻译后的显示文本或按数值相等猜测效果。

分步状态：

1. **已实现，规则回归通过**：实例旗标、ego/固定神器共享 lore 与激活知识，及其存档、合堆/拆分、遗忘语义。
2. **已实现，规则回归通过**：`obj_learn_equipped` 的明显 pval/被动属性，以及实战中抗性、杀戮、品牌等逐旗标学习入口。
3. **已实现，规则回归通过**：用实际未知旗标集合判断完全已知，避免无额外隐藏属性的普通物品仍长期停在“尚未完全鉴定”。
4. **已实现，规则回归通过**：`easy_id` 出生选项与逐诅咒旗标知识；诅咒触发学习、解除后的清理、重新鉴定与持久化。

保留的项目差异：背包“鉴定所选”是现有 `Appraise` 命令，现在与普通鉴定共用状态处理；其可达性和回合成本沿用项目现有设计，并非声称 RFB 有一个所有角色均可免费使用的同名鉴定能力。

第 2 步沿用同一来源提交：近战只学习当前武器及实际参与该手攻击的装备属性，排除工具、发射器、另一把武器和不作用于该手的戒指；射击学习当前弹药，投掷学习被投物品。拆出的弹药在飞行期间暂离物品集合，学习同时写回该单位与原来的剩余堆叠，落地保留、破损清理该单位知识。法力品牌消耗资源后学习，锐利／震击／野性／击晕／吸血在相应效果触发处学习。当前射击倍率仍沿用项目已实现的弹药来源，不额外添加原规则尚未消费的发射器或戒指品牌。

防御入口覆盖普通伤害、接触气场、地形伤害、怪物近战异常与法术异常、恐惧／精神恐怖、属性流失及生命力豁免。伤害学习在护甲后、无敌／闪避等额外减伤前进行，避免把其他减伤当作物品抗性；单纯等级／强度豁免不学习装备旗标。已有战斗规则、随机数抽取和伤害公式保持原有调用，未借此补造尚未实现的 RFB 效果。

第 3 步沿用同一来源提交的 `object1.c::_obj_flags_purify/obj_flags_unknown/obj_is_identified_fully`。未知集合排除 `HIDE_TYPE`、`SHOW_MODS`、`FULL_NAME`、`FIXED_FLAVOR`；激活仍是需要知道的 `ACTIVATE`。身份门槛与知识查询分开，避免相互递归，也避免无旗标的未鉴定物品提前公开身份。已知祝福和整组已知词缀参与其对应旗标的认知，但不补齐实例额外属性。共享 lore 学到最后一个旗标后，其他身份已知的同 ego 实例即时更新。

推导出的完全已知不写入 `identified`：该存档字段继续表示显式完全鉴定的全部知识，保留其快速路径；普通鉴定／逐项学习的完整度每次按当前属性求值，后来增加未学属性会重新成为部分已知。没有源旗标的项目属性（如额外拆除技能、穿墙）不能仅因差集为空而泄露，仍需显式完全鉴定。遗忘、付费完全鉴定及魔力吞噬者的重复鉴定消费统一完整度；保存恢复沿用已有知识字段，不另存完整度缓存，不改协议／保存格式或内容包。精细诅咒另见第 4 步。

第 4 步沿用同一提交的 `defines.h::OFC_*`、`object1.c::_obj_learn_curses/obj_learn_curse/obj_identify`、`dungeon.c::sense_inventory1/2` 及诅咒触发处。实例 `known_curse_flags: u32` 采用源位号，分别保存普通／重度／永久诅咒及现有 26 种效果；复用现有诅咒效果表，不与普通 `OF_*` 或 ego／神器共享 lore 混用。原 `known_curse` 只表达泛化的“有诅咒”认知，不公开准确严重度或整组效果。永久诅咒不自动等于重度诅咒；装备损毁保留其独立重度位。

完全鉴定重新记录当前诅咒集合，解除／祝福成功解除／平凡化清除失效知识；已经显式完全鉴定的装备后来重新受诅咒不会自动公开新效果。原版的普通属性完整度仍不包含 `OFC_*`，因此完全鉴定服务和魔力吞噬者入口另检查未知诅咒，允许再次鉴定。设施投影由核心给出普通／完全鉴定候选 ID，前端不再用“完全已知”标签过滤；简易鉴定下普通服务和批量鉴定也允许重新学习新增诅咒。逐位学习已接现有生命／法力／经验／背包装置吸取、传送、恐惧、召唤、增加诅咒、异常状态与 Ty 诅咒等生效点；无可驱散状态的 Normality、失败召唤或缺少资源时不学对应效果。现有被动惩罚不因穿戴直接公开，须实际学习或完全鉴定。知识随拆分复制、合堆比较、遗忘保留、馆藏随物品转移；存档拒绝实例实际不存在的诅咒知识位。

创建角色概览增加源中文名“简易鉴定 (*)”，默认关闭，只在创建时选择。开启后普通鉴定走完全鉴定，周期感知对所有职业启用强感知并绕过职业频率门槛，保留混乱、物品类别和背包抽样限制；感知本身不直接公开所有特殊属性。设置随角色存档保留并参与状态哈希，在原生回放记录器创建前设置；回放验证仍需与其对应的初始角色状态。

本步保留的适配：现有规则未实现的 `OFC_TELEPORT_SELF`／`OFC_CHAINSWORD` 两个位没有虚构效果或学习入口；当前战役积分使用项目自身公式，本步没有移植 `files.c` 的原版 easy_id 分数系数。背包 `Appraise` 仍限未鉴定物品，再鉴定使用既有法术／物品／设施入口。
