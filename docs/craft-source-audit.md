## 新消费者

- `do-spell.c::craft_enchant`：低阶上限为 `2 + L/5`、每次 +1；高阶上限 15、每次 +3。达到上限后仍消耗施法；禁止附魔和毒针在目标边界拒绝。提升的是基础、Ego 和实例合成后的加值；普通物品设 99% 折扣，所有目标保留原来源。此规则也由 `spells_c.c::enchantment_spell` 供神器附魔调用，I3 衔接时修正普通工艺附魔覆盖来源的差异。正常诅咒每个提升到非负的分量有一次 25% 解除机会。
- `spells3.c::polish_shield`：选择盾牌，普通、非诅咒、非镜盾成功获得原有 Reflection Ego，再进行 4–6 次护甲附魔；失败仍消耗施法。成功/失败分别调整附魔美德 +2/-2。Crafting 复用卷轴的 Ego 工厂、整叠弹药概率、知识和折扣处理。
- `spells3.c::mundane_spell`：平凡化整叠物品，保持 ID、位置、数量、铭文和书本计数；固定神器还原 `baseItemKindId`，生成唯一性账本不清除。清除实例魔法、Ego、随机神器、装置激活/充能，重新鉴定并记录 Mundanity 来源。99% 折扣 Ego 除永久诅咒外拒绝。抗性损失确认使用 `obj_kind.c::object_is_dragon_armor` 的五种龙装备，**不含龙鳞甲**。现有卷轴与法术共用此处理。无原版底材映射的原创演示神器仍不可平凡化；未导入 Vecna 手/眼不增加虚假身份。
- 元素烙印按等级开放火焰、寒冷（30）、毒素（35）、酸（40）、闪电（45）；持续 `L/2 + 1d(L/2)`。免疫选择四个基本元素，持续 `SP(13) + 1dSP(13)`。同族只有一个状态，重选替换元素和时长；Rust 投影合法选项，前端不复制门槛。
- `xtra1.c`：武器精通每把武器增加 `L/23` 个伤害骰。魔法护甲与石肤共用 `10 + 40L/50` 的 AC，互不叠加，附带豁免下限 `95+L`、混乱/失明抗性、反射、行动自如和漂浮。原说明写“免疫混乱和失明”，实际分支是抗性，按实际消费者实现。法力烙印复用已有 force 武器命中倍率及扣蓝路径。
- 活体王牌按 1/7 或地表条件获得主动传送变异，否则获得随机传送变异；复用既有变异激活、周期与保存状态。

## 验证与适配

核心证据位于 `crates/rfb-core/src/game/tests/craft.rs`：完整量身分配后拾书、发现、学习、施法、保存；附魔封顶/非法目标；盾牌反射；固定神器与装置平凡化；确认边界；烙印、免疫、武器骰、护甲、防御消费者及实际扣蓝。既有物品/能力/神器测试覆盖共用卷轴路径。桌面复现为 `npm run e2e:build` 后 `node e2e/tauri.e2e.mjs --craft`，结果记录于本机 `test-results/craft/`；实际执行结果以交付提交说明为准。

目标选择沿用本项目的施法前校验：取消不会发送命令，也不消耗费用或 RNG；这与原版部分法术在失败掷骰后打开选择器的时序不同。本批没有建立挂起施法状态。高等级核心/桌面用例显式准备等级、属性或熟练度，不代表自然练级通关。尚未开放的武僧空手专属消费者不在当前高阶法师范围内。I5 剩余 39 项书本依赖继续保留。
