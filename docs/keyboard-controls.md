# 当前键盘操作

在设置的“输入预设”或创角设置中选择 **RFB Original（已接操作）** 或 **RFB Roguelike（已接操作）**。只保留这两套区分大小写的方案，默认 Original；独立 numpad／vi／WASD 预设已移除。两者只承诺下表已有操作，尚不是全部原版命令兼容。

设置窗口与物品栏同尺寸，按游戏界面、操作与行走、显示与信息、字形、配色、导入及待保存修改分类；`%`／`&`／`!` 仍直接定位对应页。`p` 宠物菜单采用相同尺寸与三组布局。底部只常显地牢信息；任务通过 `Ctrl+Q`／任务页、存档通过 `Ctrl+S`／`Ctrl+X` 和标题存读档菜单，战役信息通过知识／角色记录查看。

## 通用入口

### 帮助与知识

所有预设可用 `?` 打开中英文操作手册、`~` 打开统一知识菜单，地图工具栏提供同名按钮。手册按 12 个主题组织，命令章节显示当前输入预设；`/` 聚焦正文搜索，目录按钮跳到章节，Tab／Enter 导航，Esc 关闭。手册说明当前实现，不将原版尚未移植的功能描述为可用。

知识菜单沿用原版五组、22 个区分大小写的字母入口，选中后先显示当前资料范围。资料页叠加在菜单之上，关闭返回该条目；Esc 返回目录，再按 Esc 关闭。已接背包／装备检视、自动取物规则、材料、已知怪物／唯一筛选、当前设施通缉资料、只读宠物与维持、地图概览、任务、字符图例、角色／攻击／美德／变异／熟练度／能力资料和当前旅程分数。宠物指挥仍从 `p` 打开。

`~` → `o`／`a`／`e` 直接查看本角色已认识的物品类型、神器和 Ego 档案；`m`／`u`／`k` 查看怪物见闻、唯一怪物存活状态和累计击杀；`d` 查看实际到访地下城的最深层数。档案页支持名称／说明搜索（`/` 聚焦）、展开详情、唯一怪物存活／死亡筛选和 Esc 返回。`~` → `H` 打开本机跨角色高分榜；通缉资料只在当前设施投影包含该信息时显示。

发现由 Rust 在出生、实际行动、鉴定和换层时记录，随原生角色存档保存；丢弃、出售、消耗、离层和实例重建不删除已记资料。普通类型须已认识，固定神器须鉴定，随机神器名称须完全鉴定，Ego 须已经识别；随机物品条目保留名字与类型说明，不重建失去物品的全部随机属性。怪物记忆只记录可辨认的投影身份，模糊感知／幻觉不揭示真实种类，伪装仅记录当时所见身份；详细属性沿用持久的调查／探测知识，不新增原版逐次战斗学习每条抗性、招式的 lore 抽样。累计击杀沿用 Core 的玩家归属，非归属死亡、解散与到期不算击杀；只显示已辨认或调查的种类。存活状态根据永久死亡／守卫记录，而非当前生成占用或所在楼层。

地下城记录实际最深到达层数，随机入场及召回同样记录，未到访地点不列出；此表不提供快捷传送。查询不修改状态或 RNG；读档不补记新的发现，损坏的身份、重复记录与不合法深度拒载。协议 1.287、save payload 40、State Hash Schema 145；沿项目约定从新开发存档开始。来源仍为下述 master 提交的 `cmd4.c` 知识浏览、`r_sights`／`r_pkills`／`max_dlv` 与现有鉴定、调查、死亡规则。

键盘入口保留编辑框、IME、修饰键、弹窗、目标／方向选择隔离，连续行动期间先停止再打开。新快照、加载、新局、返回标题关闭旧菜单；规则编辑等资料页中的显式操作仍按其自身规则执行。

来源：RFB `master@a0d92b6378d148c5262cc236b8fa6ed2ca06a54c`，`src/files.c::do_cmd_help`、`lib/help/start.txt` 与 `src/cmd4.c::do_cmd_knowledge`。知识中文菜单名逐字采用源字符串；帮助正文依据本项目实际操作编写，不导入整套原版文档或外链。

### 角色结束与高分榜

Original／Roguelike `Q` 或 `Ctrl+C` 打开结束角色确认；Original 另支持 `Ctrl+K`。命令菜单提供同一入口。先确认，再输入 `@`；取消或其他输入不发送命令、不改变分数和回合。普通角色结局为“放弃冒险”，胜利者可在当前位置退休。该命令不推进回合、世界时间或 RNG，不参与次数前缀重复、上一命令或宏录制。

实际死亡、胜利退休和放弃冒险后，Rust 原生层自动将最终成绩与角色检查点一起写入本机档案。写入失败不提交角色结束；旧存档恢复到最新终态，不能复活该角色或重复入榜。同名同种子的另一次创角有独立身份。最终榜按分数降序、同分回合升序排列，显示姓名、种族／职业、等级、分数、回合、结局、地点和结束时间。标题页、结束页及 `~` → `H` 均可查看，读取错误明确显示。

计分继续沿用当前 Core 的战役规则（地下城征服、任务完成、胜利加分及回合扣分），没有移植原版完整计分公式，也没有跨设备云端排行榜。榜单属于本机共享档案，不随单个角色存档导出；不回填过去未记录的死亡。规则来源为 `master@a0d92b6378d148c5262cc236b8fa6ed2ca06a54c` 的 `src/files.c::do_cmd_suicide` 与 `src/dungeon.c` 命令分发，确认输入采用 `@`。

### 配置与记录

所有预设可用 `@` 打开宏设置／自定义键位、`Enter` 打开可搜索命令菜单、`:` 写笔记、`)` 或 `Ctrl+]` 打开地图导出。设置和地图工具栏均有按钮入口。Original 的 `Ctrl+E` 同样打开宏设置；Roguelike 的 `Ctrl+E` 仍旅行到未知物品，先按反斜杠可使用原版含义。

自定义映射分别保存于五种预设。捕获触发键后选择原版命令或寄存器；重复保存替换该触发键，删除／清空恢复预设原义。支持全部预设映射 JSON 导入替换／导出，输入在写入前校验。映射只在地图命令边界展开一次，不改写后续方向、物品标签、编辑框或弹窗输入。所有预设的反斜杠都可绕过下一键映射，Escape 始终保留取消。命令菜单直接执行原版入口，不受用户映射影响；方向、目标和物品选择继续由原有流程完成。`Enter` 菜单是本版固定入口，不新增原版 command_menu 选项或抢占 `x/X`。

Original／Roguelike 按双引号，再选 `a-z/A-Z/0-9` 寄存器，录制下一条可重复游戏命令及已选择参数；单引号选择回放，双单引号保持列表，点号回放上一命令。宏编辑器支持录制多条单次命令、追加上一单次命令、删除、上移、复制和回放，最多 256 步。回放复用 Core 派发和已有物品／能力确认，逐步等待结果；Esc、停止按钮、其他操作、失焦、隐藏页面或保存中断后续步骤，受伤、敌人、重要发现、强制选择、移动受阻和换层等也会停止。

**录制适配范围：**这是已执行命令与参数的会话宏，不是原版终端按键串或 `.prf` 宏解释器。键位映射持久保存，所有寄存器／宏在换层、荒野坐标滚动、读档或新局时清除，避免旧实例参数命中另一物品／怪物。多步宏不录制文本、购物、保存、永久角色选择或跑步／休息／旅行调度；这些连续操作仍可用单命令寄存器重放。无效或不支持的录制结束并保留此前步骤；取消空录制不会覆盖旧寄存器。未新增原版通用偏好指令、逐类视觉／调色编辑或 `^` 控制字符前缀。

笔记最多 1000 字符，附角色、位置、回合和附近 50×24 范围的已知字符地图，并写入消息；保存在本机独立笔记本，可逐条删除和导出文本。笔记不属于原生游戏存档，跨设备需单独保留导出文件。PNG 导出当前渲染地图，TXT 导出已知地图，HTML 离线包含二者；不截取其他应用、不揭示未知格，不把用户文本作为 HTML 执行。笔记、配置与截图本身不消耗游戏回合或 RNG，不修改 Core／协议／存档格式。

来源同上，实际读取 `src/cmd4.c::do_cmd_macros/do_cmd_note/do_cmd_save_screen`、`src/util.c::repeat_check/request_command` 和 `src/dungeon.c` 分发。保留项目 MPL-2.0 文件声明；菜单与记录机制按本项目输入和保存边界改编。

所有预设都支持 `Ctrl+S` 保存当前槽位、`Ctrl+X` 保存成功后退出、`Ctrl+Q` 任务页、`Ctrl+P` 消息面板、`=` 设置。保存先等待在途命令与必要的钓鱼／跑步／自动探索取消；首次保存自动建槽，另存为才询问名称。取消或写入失败均不退出。游戏菜单可保存／另存为／读取，标题页可继续最近存档；存档位于 EXE 旁的 `userdata`，见[游戏内存档](builtin-save-system.md)。

普通命令只在地图输入上下文触发；文本框、IME 和对话框保留自己的输入。连续行动期间的普通操作键先停止行动，不连带执行新动作；保存快捷键直接进入上述等待边界。原生选择框使用方向键与 Enter，Escape 取消。

## 物品选择

公共物品选择弹窗每页最多 26 件，默认 a–z 标签：按显示标签直接选择，没有精确标签匹配的大写字母查看对应小写物品；方向键移动选项，Enter 确认，Escape 取消。保留鼠标与 Tab 焦点导航，按钮上的 Enter／空格仍操作该按钮。PageUp／PageDown、空格或前后页按钮循环翻页；标签只对应当前显示页。

来源按钮只显示该动作有合格候选的背包／装备／箭袋／地面。`/` 和 `\` 循环来源；Ctrl+P／E／Q／F 分别直达，各来源保留自己的页码。`-` 转到地面，仅一件合格物品时直接选择，多件时等待选择；Ctrl+F 只切换。没有对应来源时保持当前页，不能借切换选择远处或不合格的物品。

铭刻 `@1` 给通用数字标签，`@q1`、`@ma` 等只匹配标准命令字符，两套预设采用相同语义。按铭刻顺序取首个有效标签，同页冲突由后面的物品占用，被挤掉的物品重新分配空闲小写字母。`@` 或对应按钮暂停／恢复标签覆盖；数字 3／9 优先匹配标签，没有匹配才翻页。`!q`、`!d`、`!*` 等在公共选择时要求确认，暂停标签不会停用保护，拒绝确认仍留在弹窗。

直接物品按钮使用同一套铭刻确认。学习／浏览／施法快捷入口有书本时先选书，再定位既有法术列表；能力物品目标、充能和多个燃料来源复用物品选择。食魔者体内槽保留原标签，物品目标使用公共选择；多目标逐项选择，按顺序提交，可点“完成目标选择”结束。

标签绑定物品实例，列表重排不会改选其他物品；物品失效、来源改变或游戏快照替换后拒绝旧选择。载入／重置会关闭旧弹窗，重复命令继续使用实际 ID／槽位／数量／目标。取消遵守该操作原有规则，包括装置流程的取消费用；装备槽与戒指交换保留原槽位选择。I6 已完成统一测试及普通 standalone 桌面专项，当前 EXE 包含这些操作；实际场景和保留适配见[验收记录](item-selection-plan.md#i6-统一验证记录)。

发现档案批次补充：若地面 Ego 等物品超出当前 COST_REAL 估值器支持范围，预感明确显示无法完整评估，不再断言崩溃，也不以零价值代替；同层神器仍优先返回特殊预感。

## 休息模式

Original／Roguelike 按 `R`，或点击“选择休息模式”：输入正整数休息指定回合（上限 9999），`*` 等待生命与可恢复资源回满，`&` 在此基础上还等待异常状态和召回／改变现实倒计时。提示默认 `&`；0、空输入或取消均不提交命令，其他非法输入提示后结束。旧预设的休息键也使用此入口。`03R` 可直接休息三回合，跳过提示；`n`／`X` 保留模式或固定次数，给重复命令加次数则改为固定回合。

`&` 等待失明、混乱、中毒、恐惧、眩晕、流血、减速（含 minor slow）、麻痹和幻觉消退，不等待普通增益结束。`*` 不因这些状态或倒计时继续等待；两种恢复模式均沿用核心当前生命、资源可恢复性与食魔者体内装置恢复规则。受伤、可见敌人、死亡、宠物负担或待选择仍会中断，所以 `&` 不是保证一次治愈中毒等伤害状态。

所有模式继续逐回合提交，可用 Esc／停止按钮、其他操作、失焦、隐藏页面、保存和会话重置停止；模式和界面队列不写入存档。两种恢复模式每轮仍设 9999 回合预算，耗尽会提示，不自动刷新预算。原版的职业特殊恢复、拟态解除及休息前姿态／唱歌处理未在本批扩展；不恢复不会自然恢复的资源。来源为 `master@a0d92b6378d148c5262cc236b8fa6ed2ca06a54c` 的 `cmd2.c::do_cmd_rest` 与 `dungeon.c:4622–4664`。

`RestUntilResources` 表示资源恢复，`Rest` 表示完整恢复，`RestForTurns` 表示固定回合。Rust 决定结束条件，前端只选择模式、维护预算并处理取消。

## 边界与验证

自动探索也可通过操作区“自动探索”按钮启动，适用于全部预设；旧 WASD 的 Z 仍是西南移动。核心仅根据已知地图选择可达边缘，走完一段再选择下一个目标。遇敌、受伤、路径失效、拾取询问或满包无法取物时停止；Escape／停止按钮、失焦和隐藏页面沿用逐步取消。没有剩余可达目标的提示不代表隔墙未知区域已经探索。只在局部地图运行，支持地表滚动，不自动上下楼或进入世界地图；加载存档不自动续行。

“前往未鉴定物品”按钮供全部预设使用。候选为已发现、非脚下且尚未普通鉴定的地面物品；有感觉的非装置只接受 Excellent／Special／Awful／Terrible／Enchanted。启用有效取物规则时接受拾取、Query 或 `=g` 铭刻，忽略／摧毁规则不作候选。按带地形附加成本的路线选点，途中物品消失、移动或变为已知就停止；到达后只执行普通落脚取物规则，不强制拾取或鉴定，也不继续找下一件。找不到目标时保留旧旅行目的地；J／Roguelike 左括号继续仍锁定原物品。保存／载入沿用普通局部旅行，不自动恢复界面旅行队列。

“搜寻”按钮供全部预设切换持续搜索；状态区显示开启状态及当前实际速度。开关本身不推进回合、世界时钟或 RNG。开启后正常移动（含跑步、探索、旅行）及原地等待各附带一次现有搜索；失败移动、传送和冲锋位移不附带搜索。发现隐藏地形或箱子机关会停止自动行走，但保留搜索模式。再次按 S／# 关闭；普通 Escape、失焦、保存不擦除模式。受伤、近战命中（含无伤害动作）、有效休息或成功开始钓鱼会关闭；生命换法力保留模式。通常实际速度 −10，骑乘仍扣减，步行光速沿用现有覆盖。存档恢复模式，但不自动发送行动。

综合交互按原版 `do_cmd_alter` 顺序处理：占格怪物 → 开门 → 撞门 → 挖掘 → 关门 → 拆除陷阱；不适用时“你攻击了空气”，仍消耗一次行动。`+` 选向阶段可用 Escape 免费取消；支持数字、当前预设方向和导航键，Ctrl＋导航／小键盘适用于全部预设，Ctrl＋字母方向仅在 Roguelike 生效。连续行动中先停止当前行动，不连带执行综合交互；空地也会向核心提交，前端不根据地图预览免除费用。输入框、IME、弹窗、瞄准、忙碌和世界地图保留各自边界。

选择依据包含伪装地形：隐藏陷阱按地面处理，未揭示暗门按墙选择挖掘；占格怪物先于地形，包含未看见和墙内目标。实际执行沿用当前近战／地形规则、友方保护、恐惧限制和混乱选向；综合交互不会行走、自动拾取、自动搜索或开箱。保留适配：原版攻击友方的确认尚未接入；当前暗门没有 digging 定义，选中挖掘后会返回现有“不可挖掘”结果，仍需搜索后开门。本批没有扩展门墙内容与独立地形检定规则。

Original `n`／Roguelike `X` 重复最近已提交并收到核心响应的游戏命令；Roguelike 小写 `n` 仍向东南移动，`Ctrl+X` 仍保存退出，也可用反斜杠后 `n`。方向、物品实例、装备槽、数量、能力、铭刻、字符及完整目标选择按值保存，不重新打开通常的选择框。物品／目标已失效时由核心拒绝，不自动改选；摧毁和物品目标操作再次确认，需要确认的能力也保留确认。传输或执行报错后清空记录。
