# 下一种族：幽灵接入计划

规划日期：2026-09-09。重写起点：`084f341f0`（树人开放与专项验收）。原版读取 `D:/codex/Frogcomposband/master` 的 `master` Git 对象，本次为 `a0d92b6378d148c5262cc236b8fa6ed2ca06a54c`。前三步已完成，见[幽灵专项审计](spectre-race-audit.md)；被动、穿墙、出生与补给已实现，正式创建入口仍关闭。

## 推荐与候选范围

推荐下一批接入**幽灵**，随后考虑**半人马**。选择依据是当前可复用的运行路径和新增玩法，不是仅补齐菜单数量。

当前包有 57 个 Race 定义、45 个正式创建入口。余下 12 个定义中，三个 `demo.race.*` 是现有法术变形用定义；小狗头人、疥癣麻风病人的定义未进入原版常规出生种族分组，不自动作为待开放入口。此次常规候选为以下七个：

| 候选 | 已核对的主要工作 | 建议 |
| --- | --- | --- |
| 幽灵 | 种族穿墙、墙内密度伤害；补齐不死/浮空/吸能/夜间出生与已有恐吓能力 | 下一批；现有魔像、不死种族和幽灵形态法术提供较多复用基础 |
| 半人马 | 等级速度、躯干护甲折减、马蹄攻击与熟练度、跳跃；无靴槽和森林移动已有部分基础 | 第二顺位；战斗与机动性鲜明，但横跨更多执行路径 |
| 吸血鬼 | 吸血饱食、日照/光照弱点、黑暗出生物资、相关恢复边界 | 待生存规则完整核对后接入 |
| 炎魔 | 人类尸体出生与献祭补给、被动成长及恶魔吐息 | 需要先确认尸体生成和补给获取链 |
| 人造人 | 装备决定经验/等级、换装重算及种族能力 | 独立成长模型，单列一批 |
| 迈雅 | 启蒙/腐化分支、领域禁用、饮食与光照等分支规则 | 需先确定完整分支与选择流程 |
| 变形怪 | 种族形态选择、消耗/维持、装备变化与各形态消费者 | 依赖多种已完成形态，后置 |

比较依据包括原版 `src/py_birth.c` 常规种族分组，`src/races_a.c` 的人造人/炎魔/半人马，`src/races_k.c` 的迈雅/幽灵/吸血鬼，以及前批已核对的 `src/doppelganger.c`。该比较不等于已完成七个种族的逐项审计。

## 幽灵已确认的起点

- [现有 Race](../packs/rfb-demo-original/races/spectre.json)保留稳定 ID `rfb-legacy.race.spectre`、原版索引 27、基础属性和寒冰/毒素/虚空抗性；已补被动、非生物/不死/夜间/吸能标签、出生装置和营养除数，正式标签与主动能力仍待后续步骤。
- 原版 `src/races_k.c:846–916` 定义浮空、保持生命、识破隐形、缓慢消化、穿墙，以及非生物/不死/夜间出生/装置吸能标志。出生为一根空手法杖与照明；能力为“恐吓怪物”，4 级、智力、消耗 6、基础失败率 50。
- [装置吸能](../crates/rfb-core/src/game/inventory.rs)已由 `device-eater` 标签消费，消耗装置能量、补充 5000 营养且不消耗物品；[出生初始化](../crates/rfb-core/src/game/initialization.rs)已有夜间标签和充满能量的起始装置。[恐吓怪物](../packs/rfb-demo-original/abilities/race-scare-monster.json)及导入映射已存在。
- [穿墙资格](../crates/rfb-core/src/game/player_stats.rs)已读取当前幽灵种族及临时状态，并区分自身资格与骑乘后的有效资格；普通移动、寻路、荒野和下马/坠马使用实际地形条件。
- 原版 `src/dungeon.c:1512` 起的墙内伤害已接入世界周期，涵盖 `FF_MOVE / FF_CAN_FLY`、无敌、幽灵形态、HP 自然/装备恢复抑制和本体伤害限额。现有正式穿墙法术的对应差异已处理；未开放的穿壁/野性天赋仍是后续来源依赖。

## 五步实施

### 第一步：完成幽灵专项审计（已完成）

已核对原版 Race、全部直接 `RACE_SPECTRE` 引用、地形通行/穿墙、世界处理、饮食、出生、美德、恐吓、同族召唤和临时形态；在[审计差异表](spectre-race-audit.md)记录来源、现有消费者、缺口和后续验收。确认 `prace` 为可永久改变的本体种族，不等于历史出生种族；骑乘穿墙要求双方资格；墙内伤害限额发生在通用受伤处理之前。

本步保持正式入口关闭，未修改运行代码或内容包。补充记录树木地形适配、恶魔领主原版破墙、缓存楼层玩家位置校验和已有生命力耗尽后的永久转化缺口。

### 第二步：接入被动与穿墙规则（已完成）

补齐现有可表达的种族被动；在共同通行路径实现幽灵的合法穿墙。区分普通墙、永久墙、地图边界、其他不可走地形和怪物占位，不能将所有不可走格都视作可穿墙。种族穿墙不改变视线规则。

依原版接入墙内密度伤害、对应恢复限制和豁免。基础伤害为 `1 + 等级 / 5`；密度分支在通用受伤处理前，按本体 `prace` 对幽灵限额到当前 HP，普通情况下可到 0 HP。不能给所有临时幽灵永久保底，也不能跳过通用伤害/超越抵扣。只在原版规定的非零伤害分支抑制当次 HP 自然恢复，保留 SP 恢复及 0 HP 特例。

原版进入允许穿墙地形通常消耗 150 能量；重写树木的地形适配不能据此误加价或误伤。骑手与坐骑必须同时满足穿墙资格；合法飞越永久山地不等于穿永久墙。死亡领域幽灵形态有自身免伤，恶魔领主原版是破墙，需纠正现有穿墙表达的关联差异。临时变形/状态结束不新增强制传送；保存加载覆盖墙内位置和离层缓存。传送仍保留独立地形要求，不因统一通行就放开墙内目的地。

验收：移动/等待/休息的世界周期、低生命、4/5 等伤害取整边界、墙内保存恢复、进出形态、寻路/荒野/骑乘，及其他既有穿墙来源对照。

完成结果：新增 12 个核心专项测试通过；188 个相关既有核心测试、导入与地形校验各 1 个测试、32 个前端事件格式测试通过。六个相关契约类别共 12 个 fixture 全部通过，无需刷新；内容锁、前端类型、Rust 格式与相关 crate 的 Clippy 检查通过。真实法术测试覆盖恶魔领主破墙和死亡领域幽灵形态；等级、种族和地形前置由核心测试设置，未声称完成正式创建或桌面试玩。

### 第三步：打通出生与营养补给（已完成）

夜间出生，发放原版空手法杖与照明，不额外发口粮；保留六职业完整装备。复用装置吸能，覆盖背包和脚下装置、部分/耗尽能量、物品保留及补给获取。普通食物与原生幽灵的药水营养按原版缩减；药水主效果顺序和临时形态分支单独核对，不沿用树人的特殊饮水公式。

验收：六职业出生、真实吸能与再次吸能、普通食物/特殊食物/药水、商店获取装置后的补给、夜间时间和保存恢复。

完成结果：[六个专项测试](../crates/rfb-core/src/game/tests/spectre_supplies.rs)覆盖六职业夜间出生、完整装备/火把/满能量空手法杖、背包和脚下装置、部分/耗尽能量、临时形态、普通食物/精灵行粮/蘑菇、药水正负营养和主效果、商店购买后吸能及保存继续行动。仅测试目录中的内容副本临时加创建标签以调用真实初始化；正式包和前端入口保持关闭。生产代码只将幽灵加入已有口粮排除，其他规则复用现有管线；同步导入输出和内容锁。

### 第四步：接入主动能力与关联消费者

复用“恐吓怪物”，接入 4 级/智力/6 消耗/50 基础失败率；施法成功与失败、SP/HP 支付、目标抗性、方向/遮挡及临时形态走现有管线。区分施法判定属性与效果强度的属性来源，不因使用智力发动就改写共用恐惧效果。

补齐“非生”种族美德，验证同族召唤 `G`、不死相关治疗/状态/恐怖豁免等已存在消费者。现有生命力扣除尚缺耗尽后的永久种族转化，单列该关联缺口的实现范围、种族依赖及验收；未闭合时保留明确缺失记录。变形怪菜单、尚未开放职业或未有的服务只记录明确依赖，不为本批虚建整套系统；已经存在的关联路径必须核对。

### 第五步：开放入口并完成专项验收

最后加入正式标签、导入输出和前端白名单；创建页、角色详情延续分点特性说明，中文名称/说明取原版，修正英文占位文字。说明穿墙代价、吸能补给和体弱特点，帮助玩家选择。

核心连续流程：六职业新建 → 吸收出生装置 → 升至 4 级 → 恐吓 → 穿入普通墙 → 等待承受密度伤害 → 离墙 → 保存/加载 → 继续行动；额外覆盖形态结束和低生命边界。升级授予和测试前置条件与真实用户操作分别记录。

桌面以 standalone Tauri 包抽查战士、死亡高阶法师、弓箭手，覆盖创建、分点说明、吸能、可达的穿墙操作、保存加载和继续行动。无法在正常短程试玩内达到的高等级或稀有边界由核心测试证明，桌面记录不得扩大声称范围。

## 验证与范围

每步运行直接相关测试、内容锁验证及必要类型/构建检查；仅刷新行为实际变化的契约类别。若穿墙和世界处理的共用改动确实改变公共投影、状态输入或 RNG，再按项目规则扩大验证。最终生成普通 `build:standalone:debug` 试玩产物，并区分专用 WebDriver 验收构建。

不保留旧开发存档兼容，不增加与幽灵无关的成长、职业或服务。下一步是第四步主动能力及关联消费者；正式开放和 standalone Tauri 验收留到第五步。
