# 音乐领域与吟游诗人

来源为 RFB `master` Git 对象，提交 `a0d92b6378d148c5262cc236b8fa6ed2ca06a54c`。本批核对 `bard.c`、`do-spell.c`、`tables.c`、`effects.c`、`dungeon.c`、`cmd1.c`／`cmd2.c`／`cmd6.c`、`spells.c`、`spells1.c`、`combat.c`、`object1.c`／`object2.c`、`ego.c`、`artifact.c`、`virtue.c` 和 `s_info.txt`。四册身份来自 `k_info.txt`，中文名称逐字采用 `kind_name_zh.inc` 和法术源字符串；32项槽位及原始参数见正式包 `legacy-music-source.json`。

## 内容与入口

新增吟游诗人职业及正式构筑 `demo.build.bard`，以魅力施展音乐领域的32首歌曲。出生短剑、软皮甲、第一册歌谱；源属性、技能成长、生命、经验、武器／双持／骑乘熟练度、感知、宠物维护、美德、声音抗性和施法负重已接入现有职业消费者。

四册为 `[学徒手册]`、`[游吟诗人之乐]`、`[瑞文戴尔的竖琴]`、`[贝尔兰的诗歌]`，保留 source kind 552–555、tval105、册序和分配门槛。前两册进入书店，四册进入完整普通生成池。创建入口、中英文名称、学习／施法和“停止唱歌”职业能力已开放。

普通竖琴对吟游诗人使用 `1 + m_bonus(2)` 的魅力生成上限；随机神器竖琴采用吟游诗人的槽位估值，神器卷轴沿源 Priestly／20% Warrior 分支。生成适用性审计已包含新的第212个构筑。尚未定义的两件固定神器竖琴仍列为缺失内容，其额外职业强化不算已开放。

## 行为与保存

- 一次持续一首歌曲；改唱时在失败检定前停止旧歌。持续歌每个玩家行动边界支付当前费用的一半，保存半点法力余额，按源深度和熟练度条件增长经验。耗尽或反魔法结束吟唱，吟唱期间暂停正向法力再生。
- 成功驱散暂时中断歌曲、撤销其增益并支付额外行动，随后在下个可行动边界扣费恢复。停止、休息、饮食／读卷轴和混乱进入现有行动链。种族／突变能力不因使用通用施法入口而自动停歌。
- 祝福、英雄、加速、五抗与潜行由歌曲状态派生；独立药水／法术增益不会被停歌删除。无敌结束的额外行动通过调度器结清，保存只接受合法行动边界。状态面板显示当前歌曲，不显示伪造的剩余一回合。
- 范围减速、恐惧、震慑、混乱、魅惑、催眠、停滞、声波／灵能伤害、恢复、鉴定、复活、符文和地震复用现有消费者。声波矢、射线和微型球分别保留投射方式及地面物品处理；伤害增强作用于实际伤害。世界扭曲按距玩家的距离衰减传送强度，并使用真实抗性及落点选择。
- 顺风耳保存演唱进度，依等级逐步增加怪物／物品探测、地图与全层照明。解离之音进入实际墙体破坏移动，并破坏脚下物品。安巴坎塔沿既有楼层重建倒计时。

新增权威 Music 状态包括当前歌曲、探测进度、中断标记和半点法力余额；进入初始化、存档完整性检查、加载续演和状态哈希。新开发存档起步，不维护旧开发存档兼容。

共享适配仍保留：状态检定／时长、尸体复活、召唤分配和落点、地图保护及有限地图传送沿现有实现；未复刻原版全部投影与怪物关系细节。解离之音已覆盖穿墙及脚下物品，尚未接入移动时对同格坐骑的分解伤害。当前界面在提交有效方向／目标前取消施法，会保留旧歌；原版进入 Music 施放函数后再取消方向会先停旧歌，此处沿现有目标提交边界，不宣称完全相同。
