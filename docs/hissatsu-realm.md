# 剑道领域与武士

来源为 RFB `master` Git 对象，提交 `a0d92b6378d148c5262cc236b8fa6ed2ca06a54c`。本批读取 `samurai.c`、`hissatsu.c`、`tables.c`、`combat.c`、`cmd1.c`、`melee1.c`、`gf.c`、`xtra1.c`、`dungeon.c`、`s_info.txt`、`k_info.txt` 和 `kind_name_zh.inc`。中文名称沿用源字符串；32 个槽位、等级和原始费用记录在正式包 `legacy-hissatsu-source.json`。

## 内容与入口

新增 `demo.build.samurai`，创建入口为“近战 → 武士”。32 项剑道、四册实体剑道书、气合及四种架势进入现有能力菜单；“解除架势”单列。出生打刀、链甲和第一册，接入源属性、技能成长、感知法力、生命／经验、武器／双持／骑乘熟练度、恐惧抗性、美德和装备感知。

四册保留 source kind 556–559、tval106、册序、普通生成门槛及价值。全部进入完整普通分配池，前两册进入书店。正式包为 1.480.0，共 17 职业、213 构筑、60 册书、2,152 项能力、802 种物品和 447 条普通分配记录。

## 规则与保存

- 学习一册中当前等级可学的全部招式；学会后不必携书。不进行普通施法失败抽签，固定原始耗气，不受减耗或熟练度折扣影响；反魔法不禁止剑道。需要实际装备近战武器，并保留混乱、恐惧和特定招式的骑乘限制。
- 气合以普通法力上限的一半充气，最高为普通上限四倍与 `5 × 等级 + 5` 中较大者。宠物或架势会阻止气合；休息也可蓄力。超额部分按源 `_decay_mana` 的定点数公式衰减，保存小数余量；正常恢复不会把超额法力直接截掉。
- 居合在敌人近战前反击，风神减少攻次并在可视时反射，光气提高六属性及近战能力并降低防护、停止生命再生，无双提供抗性、护甲及被动能力并持续耗气。装备操作、施展剑道、异常状态和气力不足进入实际撤销链；撤销同步资源与生命上限。
- 剑术复用实际武器近战、品牌／杀伤、弱点致命一击、吸血、地震、投掷返回、怪物击退及玩家位移。三向攻击、双重斩和无双三段分别执行真实攻击；飞饭纲与龙闪沿实际路径攻击。龙闪校验整条路径与合法落点。
- 百人斩在击杀后逐次请求方向，后续冲锋各耗 8 点气；方向待选状态可存读档。取消保留已经发生的攻击与支付，并完成该行动的时间结算。
- 切腹在界面要求确认并输入 `@`，提交后执行强制伤害。底层显式施展命令与其他主动结束生命的规则一样执行请求。

武士状态保存架势、反击／舍身窗口和气合衰减小数，进入协议、初始化、存档验证及状态哈希。只为武士放宽气合上限，其他职业的资源上限约束保持。使用新开发存档。

## 验收范围

专项从真实武士新档开始，覆盖全部 32 招的正式书本学习、无书施展和保存，以及四册完整普通池实际生成、拾取和学习。另验证超额气合及非法上限、衰减续演、六属性与攻次变化、架势撤销、无伤震慑、舍身、怪物回合反击、龙闪路径和百人斩取消。

武士法力烙印使用双倍武器骰积的费用，剑道投掷再乘三。通用施展事务仍在效果前支付招式费用，因此低气量时法力烙印能否触发的边界与原版效果后收费不同。共享近战命中、暴击、状态抗性、投掷、地形保护和有限地图几何沿 Rewrite 现有消费者。当前 UI 在提交施展命令前取消方向不会进入核心；核心收到剑道命令后会先解除架势。架势选择使用现有能力菜单，未复刻原版独立键盘子菜单。高等级、局部地形及目标属于测试准备，不代表自然获取高阶书、练级或通关。该批未构建 Tauri standalone 或验收 Android；武士的其他专属任务／尚未开放神器不计入本次领域完成范围。
