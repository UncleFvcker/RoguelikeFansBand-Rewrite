# 诅咒（Hex）领域

来源为 RFB `master` Git 对象，提交 `a0d92b6378d148c5262cc236b8fa6ed2ca06a54c`。实际规则来自 `hex.c`、`do-spell.c`、`tables.c`、`xtra1.c`、`combat.c`、`cmd1.c`、`cmd6.c`、`melee1.c`、`dungeon.c` 和 `virtue.c`；书本来自 `k_info.txt` 与 `kind_name_zh.inc`，生成适用性核对 `object2.c`、`ego.c` 与 `artifact.c`。32 个槽位、源等级／费用／失败率及书本身份记在正式包 `legacy-hex-source.json`。

`tables.c` 的权威领域名称是“诅咒”；“咒术”对应 Sorcery。法术及书本中文名逐字保留源字符串。复仇的源说明仍为英文，本批保留该说明。

## 内容与入口

新增 `demo.build.high-mage-hex`，普通创建入口为“魔法 → 高阶法师 → 诅咒”。复用高阶法师的智力施法、成长、书本学习和职业能力；源职业入口是高阶法师的 Hex 领域，没有额外创建独立职业。

四册为 `[诅咒手册]`、`[高等诅咒]`、`[诅咒与拼写]`、`[禁忌诅咒书]`，source kind 560–563、tval107；保留册序、价值及普通生成门槛。四册进入完整普通分配池，前两册进入书店。32 项法术另配停止全部及 24 项停止单个持续法术的菜单能力；单项停止在 35 级开放，菜单只列正在维持的法术。

正式包／lock 为 1.481.0，共 17 职业、214 构筑、64 册书、2,209 项能力、806 种物品和 451 条基础分配记录。

## 规则与保存

- 同时维持上限为 `min(等级 / 15 + 1, 4)`，满额时不能施展额外法术。持续费用为各法术当前费用之和除以三，再加持续数量减一；保存 32 位小数余量。持续练习按源熟练度／等级／深度条件增长。
- 驱散暂时中断并撤销增益，下一次持续结算支付费用后恢复；反魔法、法力不足和休息停止吟诵。普通喝药停止吟诵，吸入药水保留吟诵；读卷轴仅在不足 35 级或维持数量已满时停止。停止能力耗 10 能量。
- 邪恶祝福、恶魔光环、邪恶感知、寒冰护甲、电击斗篷、力量及体魄增益接入现有属性、感知、再生和接触反伤。吟诵数量带来潜行惩罚；诅咒防具的护甲加成不要求正在吟诵。
- 诅咒武器／防具在实际装备目标上生效，保留神器／祝福抵抗、可能减附魔、重诅咒、永久诅咒及稀有旗标；界面先确认。吸取诅咒保留永久与重诅咒分支。符文剑、吸血之刃及混乱触击进入真实武器伤害、杀善、锋锐、吸血与命中状态消费者。
- 治疗、毒雾、吸血雾、精神吸取、震慑、尸体复活、充能和渐进恢复复用现有生命、资源、状态、尸体及装置消费者。影移核对邻近怪物、目标与失败随机移动，通过共用传送处理执行落点及禁止传送约束。
- 反传送、反繁殖和反魔法结界在怪物实际传送、繁殖与非天赋施法处按源等级概率拦截。暗影披风要求诅咒披风，并由实际怪物接触触发反伤。
- 忍耐／复仇记录玩家实际承受的伤害。忍耐到期或达到阈值后释放周围地狱火；复仇到期才请求方向。方向待选状态可保存，取消保留待选且不额外推进世界，选向后完成攻击并清空蓄积状态。

活动位、中断标志、法力小数、复仇倒计时／伤害／原施展结果进入协议、初始化、存档验证和状态哈希。非法瞬时法术活动位、未学习的持续法术、冲突的复仇待选状态会拒绝加载。禁止手动遗忘 Hex 法术；正常等级降低不把已启动的四项吟诵变成非法存档。使用新开发存档。
