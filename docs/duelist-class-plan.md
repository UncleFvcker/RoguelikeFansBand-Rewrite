这不是按职业文件大小排名。决斗者的风险集中在普通近战和怪物攻击的交叉消费者，工作量为中等偏大；第一步必须把这些分支审清，不能做成“加八个技能按钮”的小改动。相比刚完成的狂战士，决斗者提供单目标收益与多目标风险、装备约束和主动隔离战场，玩法区别明确。

## 完成范围

目标是正式新建决斗者，完成 1–50 级成长、八项能力、完整挑战与攻防规则、当前可达的职业关联、保存恢复及 Tauri standalone 验收。按已开放种族提供组合，不用仅允许人类来回避交叉问题。

职业基础修正为 STR +2、INT +1、WIS −2、DEX +2、CON −3、CHR +2；生命系数 100、基础 HP 4、经验系数 150、宠物维持除数 35。无普通书本/MP 施法，职业能力使用 HP。技能、熟练度、物品感知及出生美德按完整消费者审计落实，不从近似职业复制。

| 等级 | 原版显示名 | 基础 HP 费用 / 失败率 | 必须保留的区别 |
| --- | --- | --- | --- |
| 1 | 标记目标 | 0 / 0% | 单一挑战目标；唤醒并敌对化；重复标记、取消、主动清除与自动挑战分别核对 |
| 8 | 冲锋 | 10 / 0% | 沿路径最多 5 格；可能被其他怪物挡住并攻击它，不是狂战士的相邻越过攻击 |
| 16 | 侧步 | 8 / 0% | 视线内距离 10 传送，核对星界向导的行动能量例外 |
| 24 | 脱离战斗 | 25 / 0% | 需要可见的标记目标，距离 100 传送并清除标记；阻止该敌人跟随 |
| 32 | 杂技冲锋 | 30 / 0% | 最多 7 格，途中怪物的唤醒/位移/占位必须沿真实移动规则执行 |
| 40 | 孤立 | 60 / 0% | 对视线内除标记者外的怪物施加传送；距离参数为等级 ×4，保留传送抗性及 DEX 豁免 |
| 45 | 灵动决斗 | 60 / 0% | 最多 5 格冲锋；只有满足源成功判定且挑战身份仍成立时才侧步，核对击杀/接触伤害/换层中止 |
| 48 | 相位冲锋 | 80 / 0% | 最多 10 格，允许穿过源规则允许的阻碍；永久地形、落点、占位和中途攻击不可绕过 |

`MAX_DUELIST_SPELLS` 为 9，但最后一项是哨兵，实际能力是八项。上表是基础值；装备失效、状态限制、费用、扣费时序、失败与取消由 Rust 权威判定。复用现有 Class HP 路径前，要核对本职业的源施放包装器；不能直接继承狂战士的物品禁用、常驻狂暴或反魔例外。

必须一起完成的被动与状态规则：

- **挑战身份。** 使用实体实例 ID，不使用怪物种类、坐标或可见列表位置。手动标记与普通近战自动挑战都必须实现。源中某些自动挑战会用本次攻击发出挑战而不造成伤害；不能同回合白送一次受益攻击。反击、空手/种族攻击、友方/宠物、不可见和重复目标逐一审计。
- **装备失效。** 护甲总重量超过 `120 + 3L`（原版重量单位）、盾牌/捕获球、多武器、毒针、反魔会干扰天赋；按真实槽位和装备实例计算。源行为主要是天赋失效，不等于一律禁止装备。切换装备/变形/状态后及时清理挑战，卸下恢复时不得恢复陈旧目标。
- **攻次与属性。** 源基础攻次参数为上限 100、重量 70、倍率 40；有效天赋会将正向额外攻次封顶至一次，负攻次仍可降至零。不得把“最多一次”实现成强制一次。基础 AC −50，天赋有效时增加 INT 索引相关护甲；武器伤害依 DEX 索引、等级和重量计算；双手加成例外从实际消费者核对。
- **对手相关攻防。** 命中/特殊打击只对正确挑战者生效；近战来源的 AC +100、按源顺序减伤和 `15 + L` 额外豁免不能全局加到无关攻击上。远程/法术/恐惧/诅咒等来源也要审计，避免漏分支或重复减伤。
- **成长打击。** 10/15/20/25/40 级的伤害、减速、创伤、震慑和重创覆盖真实 RNG、目标免疫/唯一性、当前 HP、吸血及死亡顺序。源执行顺序含先判 25 级震慑再判 20 级创伤，不按等级排序重排 RNG。
- **物品与任务。** 当前集成已经实现共享生成、随机神器和正式任务；本职业涉及的基础分配、Acquirement、职业 bias、自动拾取/销毁、公会及奖励都是实际可达消费者，不能沿用旧文档“系统尚未实现”而跳过。需要新增的固定神器按已有 ID/来源流程导入，技能激活复用公共效果。

取消语义须显式设计：原版在目标选择取消后可能清除现有挑战，而本项目已有“取消不改变状态/RNG”的交互约定。拟保留 Esc 纯取消，提供明确“解除挑战”操作来表达清除意图；第一步固定清除的 HP/行动/RNG 语义并记录适配差异，不把状态修改藏在通用取消中。

挑战目标死亡、删除、离层、改变阵营或玩家改变职业/形态时分别依据来源处理；同层目标正常移动/传送不能仅因坐标改变而丢失标记。存档对越界/错误实体引用做真实边界校验，不能吞错后随便绑定同类怪物。投影不暴露未获得的怪物当前位置或知识。

本批不新建通用挑战管理器、第二个 HP 池、多目标标记系统或旧开发存档兼容层。`game/mod.rs` 只增加必要状态与接线，不堆入整套职业规则。

## 验收与版本

**核心最小行为集：** 普通出生与种族装备合并；真实经验升级到能力/打击边界及 50 级；标记 A 后攻击 A/B、由 A/B 近战/施法/恐惧攻击的差别；睡眠唤醒、自动挑战只挑战不攻击、重复标记与取消；装备重量阈值两侧、盾牌/捕获球/双持/反魔导致失效；恢复天赋不复活旧标记；额外攻次封顶和负攻次为零。

**能力与交叉：** 八项全部实际执行；HP 不足/恰好等费、目标取消、无目标、效果前后扣费、吸血/接触伤害/死亡时序；冲锋路径阻挡、其他怪物占位、陷阱/危险地形、野外滚动、目标移动与永久墙；传送禁用/抗性/跟随；孤立排除标记者并区分抵抗者。优先复用冬贝利负攻次、托姆特装备合并、幽灵穿墙/恢复及已有形态/突变测试，按实际受影响规则加代表案例，不复制全种族矩阵。

**保存与契约：** 至少一条“标记 → 普通攻击或冲锋 → 保存 → 加载 → 相同命令”链比较完整状态和 RNG；覆盖目标已删除或错层引用的拒绝/清理边界。新增持久挑战字段预计影响 save payload 和 State Hash Schema；DTO 变化再升级协议并由工具生成绑定，具体版本在该步确定。依据实际哈希输入变化执行完整 active 契约检查，刷新须解释差异；不得把内容 hash 当状态哈希输入或用全量刷新掩盖失败。

**检查范围：** 按[验证与契约](testing.md)选择当前改动的核心、内容、本地化、协议/保存/回放、Tauri 和前端消费者。复用既有狂战士、心灵术士、移动/传送/装备测试，只补决斗者缺口；普通步骤不默认跑完整 workspace 或桌面 E2E。第五步是明确交付里程碑，运行相关完整回归和职业桌面流程，Android 不附带承诺。

## 协作边界

按[并行协作](parallel-development.md)，种族职业方向在当前 `main` 负责决斗者。规划和后续实现均先确认写入交接；共享文件不是审批点，真实重叠才协调。以当前已合入的随机神器/分配与地牢城镇实现为基础，不恢复退役工作树，不修改其他方向的未提交文件。新增关联发现后直接落入本批必要范围；不能因它跨模块就自动推给别的方向或推迟到入口开放以后。
