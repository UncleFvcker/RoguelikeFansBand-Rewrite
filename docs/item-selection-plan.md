## I4：铭刻标签与确认保护

支持通用数字标签 `@1` 和命令专用标签，例如 `@f1`、`@ma`；专用标签可为字母或数字。按原版字符串扫描顺序、标签冲突与被覆盖项的重新分配实现，不自定“通用优先／专用优先”。原版和 Roguelike 按键先归一到命令语义，菜单按钮使用同一语义，避免同一功能换预设后铭刻失效。

支持源 `@` 临时忽略／恢复铭刻标签。明确数字标签与翻页键 3／9、命令外次数前缀 0 的优先级；仅在选择弹窗内消费标签。`!d`、`!q`、`!*` 等选择确认另走统一确认入口，保留当前核心摧毁保护，不把确认改成绕过规则的授权字段。

验收：普通文字与中文铭刻、多个标签、同标签冲突、大小写、数字、未匹配命令、临时忽略、确认拒绝；鼠标和字母选择不能绕过相同确认，铭刻文本不被解析器改写。

## I5：接齐现有调用者与连续流程

覆盖装备／卸装、丢弃／摧毁、吃／喝／读、杖／棒／魔棒、激活、投掷、燃料、铭刻／去铭刻及查看。复用已有投影候选接鉴定／充能／锻造等“先选来源、再选目标”的已有入口；食魔者体内装置保持体内槽模型，仅接它实际需要的标签语义。书本选择与法术列表分开，不把物品标签误当法术标签。
