# Mogaminator：规则与保护需求归属

状态：O3 已接全局保存；O4 已编写五类保护模板与插入预览，复用现有编辑器与规则引擎，尚未编译测试。与 [全局偏好计划](global-preferences-plan.md)的 O2／O4／O7 配合，不新增第二套自动销毁器。

来源为 [O1 审计](global-preferences-audit.md)记录的 RFB `master@a0d92b6378d148c5262cc236b8fa6ed2ca06a54c`：`src/tables.c`、`src/autopick.c` 及感觉／鉴定等调用者。实现时沿用 `crates/rfb-core/src/game/mogaminator.rs`、现有规则解析器和前端编辑器。

## 入口与存储

- 全局设置只提供打开 Mogaminator 的导航；启用、规则原文、保留原本会销毁的物品、自动取物范围、保护模板和匹配说明在此集中编辑，不在两个面板重复放相同控件。
- 编辑器仍使用 `preferences.json` 中所属部分作为唯一全局持久来源。移动编辑入口不意味着把规则放回角色存档，也不另建自动拾取配置文件。
- 悬赏对象、实际物品、感觉／鉴定状态和已写入铭刻是角色事实；待确认匹配与拒绝缓存按 O1 的上下文边界处理。
- `$` 重载已保存的规则与策略；编辑、导入、应用或重载本身不执行拾取／销毁，不推进回合，不消耗 RNG。失败保留原有效规则，未保存草案保持可见。

## 原版需求的接收位置

| 原版项目 | Mogaminator 中的处理 |
| --- | --- |
| `destroy_items` | 由规则中的销毁动作表达，不保留“简易自动销毁器”总开关或第二次规则执行 |
| `destroy_feeling`、`destroy_identify` | 归感觉／鉴定后规则重新匹配的调用职责；沿用现有执行时点，不增加通用偏好开关，不把新时机接入伪装成已有能力 |
| `leave_worth` | 保护已知有价值物品的规则模板；必须有明确可知价值条件，未知价值不能猜测 |
| `leave_equip` | 保护武器／防具的规则模板，使用已有物品类别 |
| `leave_chest` | 保护未开启宝箱的规则模板；需规则能准确区分开启状态，不能只匹配全部箱子冒充等价 |
| `leave_wanted` | 保护悬赏尸体的规则模板；查询本角色实际悬赏对象，不把目标编号写成跨角色常量 |
| `leave_corpse` | 保护尸体／骨架的规则模板 |
| `leave_junk` | 保护对应杂物类别的规则模板；使用权威类别判定，不按中文名称猜测 |
| `leave_special` | 保护当前种族／职业需要的物品；只在有已实现需求谓词时提供模板，不按职业显示名硬编码或宣称全种族职业适用 |
| `destroy_debug` | 编辑器中的匹配规则、行号和错误说明，不在全局设置单列旧调试开关 |
| `no_mogaminator`、`leave_mogaminator`、`auto_get_ammo/objects` | 沿用现有启用／保留销毁物品和统一取物范围；保留 O1 已定义的 PRF 反向／组合映射 |
| `check_full_pack` | 容量与堆叠结果始终由 Core 校验，不是用户可关闭的保护模板 |
| `delay_autopick` | 如后续需要，归 Mogaminator 的执行时点工作；本批仍暂缓，不在通用设置建立占位开关 |

## 模板是普通规则文本

O4 已接武器／防具、悬赏尸体、尸体／残骸、杂物、特殊需求五类模板。Core 提供双语正文；特殊需求只覆盖现有职业 special_item_tags 与献祭谓词，悬赏读取当前角色集合。预览明确插入第一行并使用 `~` 留置，因此优先于后续销毁与拾取规则；插入只改草案，保存不处理物品。待依赖：未开启宝箱缺状态谓词；`MoreValueThan` 目前表达已知底材价值，不能冒充含附魔等因素的已知实际价值保护。用例已编写，O8 后验收。

O4 在现有编辑器增加“添加保护规则”的操作，选择条件后预览具体规则及插入位置，再写入当前草案。保存后只保留普通规则原文；没有额外 `leave_*` 布尔副本、隐藏保护列表或第二套优先级系统。

保护规则必须按现有匹配／优先级机制生效，预览说明它与已有销毁规则的顺序。不能把保护模板追加在必然先命中的销毁规则之后，却显示为已受保护。玩家可直接编辑或删除生成的规则；恢复全局默认不凭旧开关重建规则。

只开放当前解析器和 Core 能准确表达的模板。缺少谓词的项目在本计划记为规则依赖，不显示一个无效果的勾选框，不自动降级为宽泛条件。旧 PRF 的 `destroy_*`／`leave_*` 不能自动变成等价规则，继续明确诊断；玩家从模板预览中有意生成新规则。

- O2：编辑入口归位，共用全局偏好保存边界；通用设置保留导航。
- O4：补现有能力可支持的保护模板、插入预览及匹配说明；确定缺失谓词，保留单一执行链。
- O7：共用规则校验、错误诊断和 `$` 重载；不新增旧简易销毁开关的自动转换。
- O8：收口用例，覆盖保护命中、顺序冲突、未知状态、角色悬赏切换、编辑／重载不执行物品操作，以及失败不污染已有规则。依用户安排，O8 结束后再编译测试；本次未执行。
