# Original content packs

本目录只包含为 RoguelikeFansBand Rewrite 单独创作或按已记录兼容行为独立表达的游戏数据，按 CC BY-SA 4.0 授权。

旧 RoguelikeFansBand、Frogcomposband 和 Angband 的描述文本、算法、成套数值表与素材不会无选择地整包复制到这里；每个正式兼容批次都有固定来源、严格选择和范围文档。`rfb-demo-original` 是用于验证稳定 ID、内容编译、地图与 tileset 接口的独立实现包；荒野 W0 明确纳入 RFB `master:w_info.txt` 的 normal 世界图，但只激活已经存在的 Outpost 与 Warrens，边界见 [`wilderness-w0-authoritative-data.md`](../design/wilderness-w0-authoritative-data.md)。Phase 17 的 Warrens 批次按固定来源记录的层数和 gameplay 角色重新表达，差异见 [`contract-v150-warrens-journey.md`](../design/contract-v150-warrens-journey.md)。按用户明确选择加入的 Warrior 小切片只固定该职业、Standard 身体和四件出生物品所需的少量字段，描述仍为重新撰写，未开放批量迁移，边界见 [`contract-v151-warrior-and-dungeon-status.md`](../design/contract-v151-warrior-and-dungeon-status.md)。Warrens 地图生成只移植可观察行为，以独立的洞室 mask、通道与楼梯算法实现；自由房间分布、矿脉与怪物密度的后续纠偏见 [`contract-v153-warrens-map-generation.md`](../design/contract-v153-warrens-map-generation.md) 与 [`contract-v155-warrens-generation-density.md`](../design/contract-v155-warrens-generation-density.md)。楼层/怪物掉落、金币、食物和光源只录入本次批准的小批功能字段与独立描述，范围见 [`contract-v156-warrens-loot.md`](../design/contract-v156-warrens-loot.md)、[`contract-v157-gold-wallet.md`](../design/contract-v157-gold-wallet.md)、[`contract-v158-food-hunger.md`](../design/contract-v158-food-hunger.md) 与 [`contract-v159-fuel-light.md`](../design/contract-v159-fuel-light.md)。Outpost 战术地表与商店使用独立设计的地图和身份；只提取当前补给院小批次所需的 RFB 价值、分类和可观察定价/维护规则，边界见 [`contract-v160-outpost-content.md`](../design/contract-v160-outpost-content.md)、[`contract-v161-general-store-transactions.md`](../design/contract-v161-general-store-transactions.md) 与 [`contract-v162-outpost-supply-court.md`](../design/contract-v162-outpost-supply-court.md)。

当前 `rfb-demo-original` 为内容包 `1.331.0`，content hash 见 [`content.lock.json`](rfb-demo-original/content.lock.json)。
当前包共 104 terrain、1402 actors、316 items、1666 abilities、152 mutations、16 ability books、11 affixes、1 resource、10 skills、54 skill sets、46 races、6 classes、2 personalities、9 builds、2 encounter tables、15 loot tables、0 vault、2 towns、4 town facilities、19 shops 和 1 world。
New Game 与内置规则基座统一进入 Middle-earth，当前开放已对齐 RFB 的 Warrior、死亡/奥秘/咒术/毁灭领域 High-Mage、Archer、固定死亡领域 Paladin、Cavalry 和 Sniper，均从 Outpost 开始；四个领域各有四册、32 个法术及正式获取路径。原创职业构筑及不完整职业原型已经退役。Outpost 已增加原版蘑菇店与白马旅店，后者提供食物饮料、20 金币住宿、已访问城镇旅行，以及依次解锁的任务“家里的麻烦”“乌鸦巢”“柳树老头任务”“蒸汽任务”和“旧城堡”；盗贼巢穴归伯爵府。Warrens 保持 campaign 起始胜利地牢，Orc Cave 已在 `(30,45)` 激活 15–32 层、完整生态、最终守卫奥斯罗德和战斗之戒奖励。Original Lab、Echo/Resonance 地牢、任务裂隙及其独占测试内容已经退役。物品 P1–P3.8 及 P3.7-M0–M7 的变异边界见 [`phase-19-legacy-item-integration.md`](../design/phase-19-legacy-item-integration.md) 和 [`handoff-p3-7-mutation-system.md`](../design/handoff-p3-7-mutation-system.md)，阿南巴多城镇边界见 [`town-system-handoff.md`](../design/town-system-handoff.md)，荒野边界见 W0–W5 文档。
